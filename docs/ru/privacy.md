# Политика конфиденциальности

<p class="meta">Capital для Android (пакет <code>dev.capital</code>) · Разработчик: {{ site.developer }} · Действует с 30 сентября 2026 г.</p>

## Кратко

- В Capital нет учётных записей, аналитики, рекламы, отчётов о сбоях и серверов разработчика. Разработчик никогда не получает ваши данные.
- Ваши финансовые записи хранятся только на вашем устройстве, в выбранной вами папке. Их можно зашифровать паролем.
- Единственный сетевой трафик — запросы, которые приложение по вашей команде отправляет выбранным в настройках провайдерам данных о ценах и блокчейнах. Эти запросы содержат отслеживаемые вами публичные адреса кошельков, контракты токенов и коды валют, а также API-ключ, если вы ввели его для этого провайдера.

## Что приложение хранит на устройстве

**В выбранной вами папке.** Копилки, активы, адреса кошельков, цели, привязки, плановые пополнения, кэшированные цены и настройки, относящиеся к этим данным. Файлы хранятся открытым текстом, если вы не включили шифрование (Настройки → Безопасность). При включённом шифровании каждый файл шифруется по AES-256-GCM ключом, полученным из вашего пароля с помощью Argon2id. Восстановить пароль невозможно.

**В закрытом хранилище приложения** (недоступно другим приложениям):

| Данные | Назначение |
|---|---|
| Доступ к выбранной папке | Повторно открыть папку при следующем запуске |
| Введённые вами API-ключи провайдеров | Отправляются только выдавшему их провайдеру; зашифрованы ключом из Android Keystore; не попадают в снимки, экспорт и системные резервные копии |
| Настройки блокировки | Разблокировка зашифрованной папки без пароля: копия ключа данных, зашифрованная ключом, полученным из вашего PIN-кода и привязанным к Android Keystore. Сам PIN-код не хранится |
| Выбранные язык и тема | Настройки интерфейса |

Резервное копирование Android и перенос данных между устройствами для приложения отключены, поэтому система ничего из этого не копирует ни в Google, ни на другое устройство.

## Что покидает устройство

Capital обращается только к провайдерам, выбранным вами в настройках, только по HTTPS и только когда вы обновляете данные или проверяете источники. Ответ на каждый запрос обрабатывается, а сам запрос отбрасывается; в вашей папке приложение сохраняет полученные балансы и цены, а не запрос.

| Какие данные | Кому | Зачем |
|---|---|---|
| Добавленные вами публичные адреса кошельков | Провайдеру данных блокчейна, выбранному для этой сети | Прочитать баланс и токены на адресе |
| Адреса контрактов токенов и идентификаторы активов | Выбранному вами провайдеру цен криптовалют | Оценить активы |
| Коды валют | Выбранному вами провайдеру курсов фиатных валют | Пересчитать валюты |
| API-ключ, введённый вами для провайдера | Только этому провайдеру | Авторизовать вашу собственную учётную запись у него |

Как и при любом интернет-запросе, каждый провайдер видит ваш IP-адрес. Провайдеры не зависят от разработчика и обрабатывают запросы на своих условиях и по своим политикам конфиденциальности; ссылки на них есть в приложении в разделе Настройки → Источники и авторство:

| Данные | Провайдеры |
|---|---|
| Bitcoin | [Blockstream](https://blockstream.info), [mempool.space](https://mempool.space) |
| Ethereum и токены ERC-20 | [PublicNode](https://publicnode.com), [Alchemy](https://www.alchemy.com), [Blockscout](https://www.blockscout.com), [Ethplorer](https://ethplorer.io) |
| TON и жетоны | [TON Center](https://toncenter.com), [TonAPI](https://tonapi.io) |
| TRON и токены TRC-20 | [TronGrid](https://www.trongrid.io), [PublicNode](https://publicnode.com) |
| Цены криптовалют | [DefiLlama](https://defillama.com), [CoinGecko](https://www.coingecko.com), [CoinPaprika](https://coinpaprika.com) |
| Курсы фиатных валют | [Frankfurter](https://frankfurter.dev), [Европейский центральный банк](https://www.ecb.europa.eu) |

Больше никуда ничего не отправляется. Данные не продаются, не передаются для рекламы и не используются для составления профилей. Запросы к публичным блокчейнам раскрывают, что отслеживаемый адрес интересует кого-то с вашим IP-адресом; если это для вас важно, пользуйтесь VPN.

## Чего приложение никогда не делает

- Никогда не запрашивает, не хранит и не передаёт приватные ключи и seed-фразы. Оно не может подписывать или отправлять транзакции.
- Никогда не переводит деньги. Распределение по целям — это только расчёты, которые показываются вам, и ничего больше.
- Никогда не связывается с разработчиком. Нет телеметрии, нет проверки обновлений внутри приложения, нет push-уведомлений.

## Разрешения

| Разрешение | Для чего |
|---|---|
| Интернет | Запросы к перечисленным выше провайдерам |
| Доступ к папке | Вы предоставляете его через системный выбор папки Android для выбранной папки; другие папки приложение читать не может |
| Биометрия | Разблокировка отпечатком пальца или по лицу через системный запрос Android; приложение получает только результат «успех» или «неудача», но никогда — биометрические данные |

## Синхронизация и резервные копии

Capital ничего не синхронизирует сам. Если вы подключите папку к средству синхронизации (Syncthing, Nextcloud, Google Диск, …), к создаваемым им копиям применяются условия конфиденциальности этого средства. Файлы хранятся открытым текстом, если шифрование не включено; копии без шифрования, сделанные до его включения, остаются читаемыми для любого, у кого они есть.

**Экспортировать резервную копию** в настройках записывает один файл в выбранное вами место. Он содержит те же записи и защищён ровно настолько, насколько защищено это место.

## Удаление данных

Удалите выбранную папку (и все копии, созданные средством синхронизации) и удалите приложение. При удалении приложения стирается его закрытое хранилище, включая ключи провайдеров и настройки блокировки. У разработчика нет ваших данных, поэтому удалять ему нечего, и он не может ничего удалить от вашего имени. Провайдеры, к которым вы обращались, могут хранить журналы запросов по своим правилам хранения.

## Дети

Capital — инструмент управления личными финансами для взрослых. Он не предназначен для детей младше 13 лет и сознательно не собирает их данные.
