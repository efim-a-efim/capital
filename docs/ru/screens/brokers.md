# Брокеры

**Что это.** Ваши подключения только для чтения к брокерским и форекс-счетам. Брокерский счёт — это брокер, ID счёта или запроса и учётные данные брокера; при обновлении приложение читает общую стоимость счёта в его базовой валюте. Счета находятся на этом экране, а не внутри копилок: копилка лишь привязывается к счёту, а сбережения по-прежнему учитываются в копилках.

**Что показывает каждая строка.** Название счёта, брокера и ID, последнее прочитанное значение в валюте счёта и в вашей валюте по умолчанию, когда оно было получено и когда загружено, а также копилку, к которой привязан счёт: **Привязан к …** открывает эту копилку, *Не привязан к копилке* означает, что пока никто его не учитывает. Кнопка **Изменить** меняет название, брокера или ID; **Удалить** удаляет счёт и, если он был привязан, актив, который его привязывал.

**Добавление счёта.** Нажмите **+**, введите название, выберите брокера и введите ID, который он использует: Flex Query id для Interactive Brokers, ID счёта для OANDA, номер счёта для Trading 212. Для SnapTrade нажмите **Подключить брокера через SnapTrade**, вернитесь, нажмите **Загрузить счета** и выберите счёт. Сохраните. Валюта и стоимость появятся после следующего обновления.

**Игнорировать остатки меньше.** Отметьте и введите сумму в вашей валюте по умолчанию (по умолчанию 1), чтобы мелочь не попадала в сбережения: если стоимость счёта, пересчитанная по кэшированным курсам, меньше этой суммы, привязанный актив считается как 0, а в строке написано *Считается как 0: меньше …*. Реальное значение остаётся видно на этом экране. Если курса для валюты счёта нет, ничего не игнорируется.

**Привязка к копилке.** Откройте копилку, нажмите **Добавить актив**, в поле **Способ учёта** выберите **Брокерский счёт** и выберите счёт; оставьте название пустым, чтобы использовать название счёта. Один счёт может быть только в одной копилке. Кнопка **Изменить / переместить** у актива переносит его в другую копилку; удаление актива отвязывает счёт, но не удаляет его.

**Учётные данные.** Токен или ключ каждого поддерживаемого брокера (Interactive Brokers, OANDA, Trading 212, SnapTrade); один набор на брокера действует для всех его счетов. Они зашифрованы ключом из Android Keystore, никогда не записываются в папку с данными, не попадают в экспорт и системные резервные копии и отправляются только выдавшему их брокеру. Кнопка **Инструкция по подключению брокерских счетов** открывает страницу [Брокерские и форекс-счета]({{ page.base }}/accounts) с шагами для каждого брокера.

**Обновление.** Значок обновления на этом экране читает все счета; обновление в копилке читает только счета, привязанные к этой копилке. Счёт, который не удалось прочитать, сохраняет последнее значение, а сообщение брокера показывается под его строкой. Приложение только читает: оно никогда не отправляет ордера и не перемещает деньги.
