# Копилки

**Что это.** Список мест, где вы храните деньги. Копилкой может быть банковский счёт, наличные, брокерский счёт, счёт на бирже или криптокошелёк.

**Что показано на карточке.** Название копилки, её стоимость в собственной валюте копилки и количество активов в ней. Нажмите на карточку, чтобы открыть [копилку]({{ page.base }}/screens/bucket).

**Добавление копилки.** Нажмите **+** в правом нижнем углу. Копилке нужны название и валюта: код ISO, например EUR или USD, либо криптовалюта, например BTC. Валюта определяет только то, в чём показывается итог копилки; активы внутри неё могут быть в любой валюте.

**Режим портфеля.** В том же редакторе есть переключатель *Режим портфеля*. Копилка-портфель показывает фактическую долю каждого актива в сравнении с заданной вами целевой долей и предлагает калькулятор ребалансировки. См. [Режим портфеля]({{ page.base }}/manual#buckets).

**Порядок.** Копилки перечислены в порядке создания. Порядок не влияет на распределение.

**Обновление.** Кнопка обновления на верхней панели обновляет все копилки. Отдельную копилку можно обновить на её собственном экране.
