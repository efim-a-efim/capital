# Trinkgeld für den Entwickler

Wenn Sie dem Entwickler ein Trinkgeld geben möchten, nutzen Sie eine der folgenden Möglichkeiten. An den Funktionen der App ändert sich dadurch nichts, aber es hilft dem Entwickler.

{% include tips.html %}

Ein Trinkgeld ist eine Überweisung aus Ihrer eigenen Wallet an die Adresse des Entwicklers. Die App und diese Website sind daran nicht beteiligt und können sie nicht sehen; nichts wird freigeschaltet, aufgezeichnet oder verändert. Dieselben Adressen zeigt die App unter der Herz-Schaltfläche in der Übersicht. Siehe [Spenden]({{ page.base }}/privacy#donations) in der Datenschutzerklärung.
