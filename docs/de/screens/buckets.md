# Töpfe

**Was es ist.** Die Liste der Orte, an denen Sie Geld aufbewahren. Ein Topf kann ein Bankkonto, eine Bargeldreserve, ein Depot, ein Börsenkonto oder eine Krypto-Wallet sein.

**Was jede Karte zeigt.** Den Namen des Topfs, seinen Wert in der eigenen Währung des Topfs und die Anzahl der Positionen darin. Tippen Sie auf eine Karte, um den [Topf]({{ page.base }}/screens/bucket) zu öffnen.

**Topf hinzufügen.** Tippen Sie unten rechts auf **+**. Ein Topf braucht einen Namen und eine Währung: ISO-Codes wie EUR oder USD oder einen nativen Vermögenswert wie BTC. Die Währung legt nur fest, wie die Summe des Topfs angezeigt wird; die Positionen darin können in beliebiger Währung sein.

**Portfoliomodus.** Im selben Editor gibt es den Schalter *Portfoliomodus*. Ein Portfolio-Topf zeigt den Ist-Anteil jedes Vermögenswerts im Vergleich zu einem von Ihnen festgelegten Zielanteil und bietet einen Rebalancing-Rechner. Siehe [Portfoliomodus]({{ page.base }}/manual#buckets).

**Reihenfolge.** Töpfe werden in der Reihenfolge ihrer Erstellung aufgeführt. Die Reihenfolge hat keinen Einfluss auf die Zuordnung.

**Aktualisieren.** Das Aktualisieren-Symbol in der oberen Leiste lädt jeden Topf neu. Ein einzelner Topf lässt sich auf seinem eigenen Bildschirm aktualisieren.
