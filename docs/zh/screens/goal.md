# 目标详情

**这是什么。** 单个目标及其资金情况。在[目标]({{ page.base }}/screens/goals)标签页中点击卡片即可进入；**← 所有目标** 返回。

**顶部信息。** 名称和标记、已到位 / 目标金额、截止日期、预测说明，以及 **仍需**：目标金额减去目前已到位的金额。

**按钮。** **编辑目标** 可修改名称、货币、目标金额和截止日期。**归档** 会保留目标但不再计入；已归档的目标会改为显示 **取消归档**。**删除** 在确认后删除该目标及其关联。

## FIRE {#fire}

**FIRE**（财务独立、提前退休）类型的目标回答两个问题：资金何时可以开始支付您的生活开销，以及能维持多久。这是对您自己数字的推算，不推荐任何东西。在编辑器中通过 **目标类型**（**储蓄目标** / **FIRE**）设置类型。

**编辑器字段。** 除名称和货币外，每个字段都可以留空；应用会根据其余内容尽量推算。

- **出生日期 · YYYY-MM-DD · 可选**：用于显示年龄，并把预期寿命设为时间范围的终点。
- **FIRE 日期 · YYYY-MM-DD · 留空则推算**：您停止储蓄、开始支出的那一天。过去的日期表示支出期已开始：计划从今天起按目标现有的资金进行。
- **我可投入 · 留空则推算**：每 **周**、**2 周**、**月**、**年** 或 **N 天** 的金额（选 N 天时再填写 **天数**）。
- **定期投入每年增长 % · 留空则按通胀**：您每年可多投入多少，例如每年加薪。留空则保持定期投入的购买力。
- **FIRE 后每月支出 · 留空则推算**。
- **FIRE 后需拥有的金额 · 留空则推算**：即 FIRE 所需金额，也就是该目标的目标金额。
- **高级假设**：**通胀率 % · 平均 / 乐观 / 悲观**、**增长率 % · 平均 / 乐观 / 悲观**、**提取率 %**、**工作至年龄**（默认 65）和 **预期寿命 · 年**。每个标签末尾都有“· 当前 {值}”，即该字段留空时实际采用的值。

所有金额均按目标货币的今日币值计。屏幕上也会显示 FIRE 日期那一天的未来币值。目标目前拥有的资金来自其关联的储蓄罐，与其他目标相同；[计划]({{ page.base }}/screens/plans)不参与 FIRE 计算。

**可推算的内容。**

- FIRE 日期：支出可维持到预期寿命（没有出生日期时为 50 年）、且在给定目标金额时已达到目标金额的第一个月；不晚于 **工作至年龄**，否则为 *该生日前无法达成*。没有目标金额时，FIRE 所需金额即为该寿命所需的金额。
- 定期投入：由目标金额和 FIRE 日期推算。
- 目标金额：已给出 FIRE 日期时由支出推算（支出 × 12 ÷ 提取率），或由 FIRE 日期和定期投入推算。
- 支出：由目标金额推算（目标金额 × 提取率 ÷ 12）。

如果 FIRE 日期、定期投入和目标金额都已填写，则保留该日期，并在屏幕上显示缺口和最早可达成的日期。推算出的目标金额和日期会写入目标的目标金额和截止日期，因此排序、分配、概览和计划都与其他目标一样运作。每次编辑和每次刷新都会更新它们。

**FIRE 部分。** 首先是各情景相同的值（您填写的内容和 **提取率**），每项一行。然后是每种情景一个可折叠的行，**平均**、**乐观**、**悲观**，显示其增长率和通胀率、留空时推算出的 FIRE 日期以及一个标签：资金可维持到预期寿命之后时为 **资金充足**（绿色），资金永不用完时为 **资金永不耗尽 🥳**（绿色），FIRE 日期无法达成或资金更早耗尽时为 **资金不足**（黄色）。点按该行可展开因情景而异的值：

| 行 | 含义 |
|---|---|
| **FIRE 日期** | 日期；已知出生日期时附带“N 岁”，或 *<日期> 前无法达成* |
| **每月投入** | 每月必须投入的金额 |
| **FIRE 所需金额 · 今日币值** | 需要拥有的金额，与编辑器中填写的一致 |
| **FIRE 所需金额 · FIRE 日币值** | 同一金额计入通胀后的数值 |
| **每月支出 · 今日币值** | FIRE 之后的每月支出 |
| **每月支出 · FIRE 日币值** | 同一支出计入通胀后的数值 |
| **现在可支出 · 每月** | FIRE 日期之前为 0。之后为本月可取出的金额：目标今天拥有的资金，按今日币值分成相等的金额支付至预期寿命 |
| **现在可支出 · 每年** | 同上，按 12 个月计 |
| **资金可维持** | *至 <日期> · N 岁*、*N 年 · 超出预期寿命*、*资金永不耗尽 🥳*，或日期无法达成时的 *缺口 …* |

折叠行下方有一行“比率：…”，说明这些比率来自哪个数据源，或 *内置默认值*。再下面的图表是资金消耗曲线：从今天到资金耗尽或时间范围终点，按今日币值显示资金的价值，三条彩色曲线分别对应三种情景。左侧坐标轴显示以目标币种计的金额，底部坐标轴显示年份（今天、FIRE 日期、终点）。虚线标出 FIRE 日期。图表下方的说明是 *基于您自己数据的推算，不构成任何建议。* 在[目标]({{ page.base }}/screens/goals)标签页中，该目标显示 *FIRE 日期 <日期> · N 岁*，或 *无法达成*。

**计算方式。** 按月逐步计算。FIRE 日期之前，定期投入按 **定期投入每年增长 %** 增长（留空则随通胀增长，从而保持购买力），资金按该情景的增长率增值。FIRE 日期之后，支出随通胀增长，剩余资金继续按该情景的增长率增值。时间范围为出生日期加预期寿命（默认 95 岁）；没有出生日期时，为 FIRE 日期之后 50 年。*资金永不耗尽* 表示资金在 200 年内不会用完，且按今日币值计，期末的价值不低于 FIRE 日期时的价值。 **现在可支出** 使用目标今天按最新价格拥有的资金，而不是计划支出，并使用最近一次刷新得到的情景比率：市场下跌时，资金和现在可支出随之下降，因此资金会留待恢复；市场上涨时则上升。

**默认值和来源。** 在没有手动覆盖、也没有获取到比率时，应用采用增长 7 %（乐观 10 %，悲观 4 %）、通胀 3 %（2 %、5 %）和 4 % 的提取率。它们出自 UBS Global Investment Returns Yearbook 2026（全球，1900–2024 年：股票名义年回报 9.8 %，债券 4.6 %，通胀 2.9 %；7 % 约相当于 60/40 的组合）、各国央行 2 % 的通胀目标，以及 4 % 规则的出处 Bengen（1994）和 Trinity study（1998）。另见使用手册中的 [FIRE]({{ page.base }}/manual#fire)。

**实时比率。** **刷新** 会按每个 FIRE 目标的货币，从[设置]({{ page.base }}/screens/settings)中选定的数据源获取通胀和市场增长数据。优先顺序是：您在 **高级假设** 中填写的值，其次是获取到的值，最后是默认值。获取失败时会保留之前的序列并显示错误。两种增长数据源都是不含股息的价格指数，因此会低估总回报。

**提示信息。**

| 提示 | 处理方法 |
|---|---|
| *请输入目标金额、每月支出，或同时输入 FIRE 日期和定期投入* | 三者填写其一；都没有就无法推算。 |
| *请输入 FIRE 日期或定期投入* | 目标金额已知，但日期和定期投入都没有；请给出其中之一。 |
| *出生日期晚于今天* | 请更正出生日期。 |
| *提取率必须大于零* | 在 **高级假设** 中填写大于 0 的提取率，或清空以使用默认值。 |
| *<日期> 前无法达成* | 按这笔定期投入和这些比率，在该日期（时间范围的终点）之前无法达到目标金额；请提高定期投入、降低目标金额或支出，或改看另一种情景。 |
| *没有 <货币> 的比率数据* | 通胀或增长数据源没有该货币的序列；请更换数据源，或在 **高级假设** 中填写比率。 |
| *ECB 不涵盖 <货币>* | ECB 只提供欧元区通胀；请在设置中为 **通货膨胀** 选择其他数据源。 |
| *OECD 不涵盖 <货币>* | OECD 没有该货币的序列（例如 RUB）；请在设置中为 **通货膨胀** 选择其他数据源。 |

**资金来源。** 可以为此目标出资的储蓄罐。**关联储蓄罐** 可添加一个储蓄罐并设置出资上限：

- **自动 — 至所需剩余金额**：在排在前面的目标取走各自份额之后，该储蓄罐补足此目标仍需的金额。
- **以目标货币计的固定金额**。
- **储蓄罐的 %**：最多为储蓄罐价值的该比例。
- **目标的 %**：最多为目标金额的该比例。

编辑器中的预览显示该关联按当前情况能出资多少。上限只是最高值：目标顺序、可用储蓄和其他关联都可能减少出资金额。列表中的每个资金来源都会显示它目前出资多少，以及为什么不能出资更多；**编辑关联** 可修改上限，**取消关联** 会将其移除。

**计划储蓄。** 能用于此目标的计划，每项都附有预测分配给它的金额。已被排在前面的目标用完的计划不会出现在这里。

**如何理解预测。** “计划储蓄将于 2026年12月20日 达成此目标 · 按时”表示截至该日期累计的计划储蓄能在截止日期之前覆盖剩余所需金额。“计划储蓄到 … 最多可覆盖 … · 还差 …”表示无法覆盖；请添加计划、推迟截止日期或降低目标金额。
