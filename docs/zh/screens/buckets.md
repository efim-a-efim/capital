# 储蓄罐

**这是什么。** 您存放资金的各个地方的列表。储蓄罐可以是银行账户、一笔现金、证券账户、交易所账户或加密货币钱包。

**每张卡片显示的内容。** 储蓄罐名称、以储蓄罐自身货币计的价值，以及其中的持仓数量。点击卡片即可打开该[储蓄罐]({{ page.base }}/screens/bucket)。

**添加储蓄罐。** 点击右下角的 **+**。储蓄罐需要名称和货币：可以是 EUR、USD 等 ISO 代码，也可以是 BTC 等原生资产。货币只决定储蓄罐总额的显示方式；其中的持仓可以使用任何货币。

**投资组合模式。** 同一编辑器中有一个 *投资组合模式* 开关。投资组合类储蓄罐会显示每项资产的实际占比与您设定的目标占比，并提供再平衡计算器。参见[投资组合模式]({{ page.base }}/manual#buckets)。

**顺序。** 储蓄罐按创建顺序排列。顺序不影响资金分配。

**刷新。** 顶栏的刷新按钮会重新加载所有储蓄罐。也可以在单个储蓄罐的界面中单独刷新它。
