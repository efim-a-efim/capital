# 设置

**这是什么。** 记录以外的一切：偏好、数据源、安全和文件夹。通过顶栏的齿轮图标打开；在宽屏设备上，它是侧边导航栏中的一个标签页。

**偏好设置。** 默认货币和主题（跟随系统、浅色、深色）。默认货币用于“概览”的估值，并作为新建储蓄罐和目标的默认货币；现有记录保留各自的货币。**语言** 会立即切换界面语言；*系统默认* 则跟随设备设置。

**免费数据源。** 每种数据类型一行，各自显示正在使用的运营方：BTC、ETH、TON、TRX 余额；ETH、TON、TRX 代币列表；加密货币价格；法定货币汇率。点击某一行可选择其他运营方、将某条链的代币查询设为 **关闭**，或填写可选的 API 密钥。密钥加密存储在设备上，只会发送给签发它的运营方。**测试数据源/刷新投资组合** 会用您实际持有的资产查询每个运营方，并报告哪些查询失败。绝不会静默替换为其他运营方。

**报价和时效。** 每条缓存的报价及其观测时间和获取时间。过期的报价仍可使用，并会在“概览”中标记出来。

**安全。** **加密** 会用密码加密文件夹中的所有文件；关闭加密会将它们解密。开启加密后，可以 **设置 PIN**、开启 **使用生物识别**、选择 **后台自动锁定** 的时间以及 **修改密码**。无法找回密码。连续输错 10 次 PIN 后，PIN 会被移除；密码始终有效。参见[安全]({{ page.base }}/manual#security)。

**存储。** 当前文件夹及其修订版本。**重新连接/打开文件夹** 会重新打开文件夹选择器；**重新加载本地文件** 会重新读取文件夹，例如在同步工具传来更改之后；**导出备份** 会写入一个可移植的文件（加密关闭时为明文，并会标明）；**恢复备份** 会先验证文件，再替换记录，并保留现有快照。

**数据来源/署名。** 每个运营方网站的链接，以及位于底部的应用版本号和构建号。
