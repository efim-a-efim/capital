# 开始界面

**这是什么。** 安装后看到的第一个界面；每当应用没有可用的文件夹时，也会显示此界面。此时还没有存储任何数据。

**工作方式。** Capital 将所有记录保存在您设备上的一个文件夹中，不会存放在其他任何地方。点击**选择或重新打开文件夹**，在 Android 文件夹选择器中选择一个专用文件夹，例如 `Documents/Capital`。如果文件夹中已有 Capital 文件，会直接打开；因此在重新安装后，或在通过同步工具接收该文件夹的另一台设备上，同一个按钮都可以重新连接您的数据。

**选择之前：**

- 警告框说明了哪些数据会离开设备：钱包公开地址、代币合约和您的 IP 地址会发送给您之后在“设置”中选择的数据运营方。切勿在应用的任何地方输入私钥或助记词。
- 默认货币为 EUR。打开文件夹后，可在“设置”中更改。

**顶部按钮。** **?** 会以应用当前语言打开本文档。打开文件夹后，才会出现刷新和“设置”按钮。
