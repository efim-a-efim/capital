# 计划

**这是什么。** 您打算存入的钱：每月底的工资、12 月的奖金、一笔退税。计划不属于您的储蓄，也不会改变任何总额。它们只用于延伸目标的预测。

**每一行显示的内容。** 计划的名称、金额和货币、日期，以及 *计划中* 或 *已归档*。铅笔图标用于编辑，垃圾桶图标用于删除。

**添加计划。** 点击 **+**，输入名称、货币、金额和日期。日期按 YYYY-MM-DD 格式输入，或从日历中选择。

**计划如何使用。** 计划按日期排序并逐笔累加。每加入一笔，应用都会用这笔额外资金重新计算分配：它在所有实际储蓄罐之后使用，按截止日期顺序分配给各目标。某个目标所需金额首次被覆盖的日期就是它的达成日期，在目标上显示为 *将按时达成*；如果晚于截止日期，则显示为 *未达成* 并注明晚了多少天。

**已归档的计划。** 计划日期过后，它会移到 **已归档** 部分，显示为灰色，不再计入。要么您已经把这笔钱存入某个储蓄罐，应用会在那里看到它；要么这个计划没有实现。把日期改到将来即可重新启用，或者将其删除。

**货币。** 以其他货币计的计划会按缓存汇率换算。如果缺少汇率，预测会被标记为不完整。
