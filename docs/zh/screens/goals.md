# 目标

**这是什么。** 您正在为之储蓄的所有事项，按截止日期分组，并按资金分配的顺序排列。

**每张卡片显示的内容。**

- 名称和标记：当前储蓄已覆盖目标金额时显示 **已达成**（绿色），计划储蓄能在截止日期前达成目标时显示 **将按时达成**（绿色），其他情况显示 **未达成**（黄色）。
- 以目标货币计的 **已到位 / 目标金额**，以及截止日期。
- 进度条。实色部分是目前已到位的金额；浅色部分是计划储蓄将来补上的金额。
- 进度条下方的一行文字：*现已达成*，或计划储蓄达成该目标的日期，或到某个日期为止仍差多少。

**顺序和优先级。** 截止日期较早的目标优先获得资金。截止日期相同的目标按所示顺序获得资金；拖动 **≡** 手柄即可调整顺序。已归档的目标位于最下方，不占用任何资金。

**添加目标。** 点击 **+**。目标包含名称、货币、目标金额和截止日期。在您打开目标并至少关联一个储蓄罐之前，目标不会获得任何资金；参见[目标详情]({{ page.base }}/screens/goal)。

**分配的工作方式。** 储蓄罐在其关联的目标之间共享，受每个关联上设定的上限约束，截止日期较早的目标优先。当一个储蓄罐关联到多个目标时，应用会在这些目标之间调配资金，避免出现一个目标资金不足、另一个却资金过剩的情况。计划储蓄只在所有实际储蓄罐之后才使用，因此绝不会取代您已有的资金。
