# 券商

**这是什么。** 您与证券和外汇账户之间的只读连接。券商账户由券商、账户 ID 或查询 ID 以及该券商的凭据组成；刷新时，应用会读取该账户以其基础货币计的总价值。账户存放在此页面，而不在储蓄罐内：储蓄罐只是关联到某个账户，您的储蓄仍在储蓄罐中统计。

**每一行显示什么。** 账户名称、券商和 ID，最近一次读取的以账户货币和默认货币计的价值，观测时间和获取时间，以及它所关联的储蓄罐：**已关联到 …** 会打开该储蓄罐，*未关联到储蓄罐* 表示目前没有任何储蓄罐统计它。**编辑** 可修改名称、券商或 ID；**删除** 会移除该账户，若它已被关联，还会移除关联它的持仓。

**添加账户。** 点击 **+**，输入名称，选择券商，并输入该券商使用的 ID：Interactive Brokers 填 Flex Query id，OANDA 填账户 ID，Trading 212 填账号。对于 SnapTrade，点击 **通过 SnapTrade 连接券商**，返回后点击 **获取账户** 并选择一个账户。保存。货币和价值会在下一次刷新后显示。

**忽略低于以下金额的余额。** 勾选后输入一个以默认货币计的金额（默认为 1），即可把零碎的小额余额排除在储蓄之外：当账户价值（按缓存汇率换算）低于该金额时，关联的持仓按 0 计算，该行会显示 *按 0 计算：低于 …*。真实价值仍会显示在此页面。如果没有该账户货币的汇率，则不会忽略任何余额。

**关联到储蓄罐。** 打开储蓄罐，点击 **添加持仓**，将 **跟踪方式** 设为 **券商账户** 并选择该账户；名称留空则使用账户名称。同一时间一个账户只能放入一个储蓄罐。持仓上的 **编辑/移动** 可将其移到另一个储蓄罐；删除持仓只会取消关联，不会删除账户。

**凭据。** 每家受支持的券商（Interactive Brokers、OANDA、Trading 212、SnapTrade）的令牌或密钥；每家券商一套即可覆盖该券商的所有账户。它们使用保存在 Android Keystore 中的密钥加密，绝不会写入数据文件夹，也不包含在导出文件和系统备份中，并且只会发送给签发它们的券商。**券商账户设置指南** 会打开[券商和外汇账户]({{ page.base }}/accounts)，其中列出了各家券商的设置步骤。

**刷新。** 此页面上的刷新图标会读取所有账户；储蓄罐上的刷新只读取关联到该储蓄罐的账户。无法读取的账户会保留其最近的价值，并在其行下方显示券商返回的信息。应用只读取：绝不会下单或转移资金。
