# 概览

**这是什么。** 主页标签页。用一个数字概括您拥有的全部资产、其中有多少已被目标占用，以及每个目标的状态。

**显示内容。**

- **已估值储蓄总额**，以您的默认货币计：所有储蓄罐中的所有持仓，按最新报价换算。如果缺少报价，总额会被标记为不完整，原币数量仍可在“储蓄罐”标签页中查看。
- **已分配给目标**：总额中各目标可以通过关联占用的部分。
- **未分配**：没有任何目标占用的部分。资金未被分配，可能是因为没有目标关联到该储蓄罐，可能是因为上限限制了关联，也可能是因为所有已关联的目标都已达成。
- **您的目标**：与“目标”标签页相同的卡片，按资金分配顺序排列，带有标记和预测说明。

**数字之间的关系。** 总额 = 已分配 + 未分配，始终成立。分配不会转移任何资金：它只表示按当前情况，某个储蓄罐会用于哪个目标。

**顶栏。** 刷新图标会重新加载所有钱包余额和价格，刷新期间图标会旋转。齿轮图标打开“设置”。**?** 打开本页。

**提示。** 当报价过期或缺失、文件夹有未保存的更改，或文件夹的两个修订版本发生冲突时，会出现黄色提示条。每条提示都有各自的按钮；参见[同步、备份与恢复]({{ page.base }}/manual#sync-backup-recovery)。
