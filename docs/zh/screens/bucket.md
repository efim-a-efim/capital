# 储蓄罐详情

**这是什么。** 单个储蓄罐及其持仓。在[储蓄罐]({{ page.base }}/screens/buckets)标签页中点击卡片即可进入；**← 所有储蓄罐** 返回。

**顶部信息。** 储蓄罐的价值，然后是两个需要结合起来看的数字：**已分配**，即已关联目标占用的部分；**可用**，即其余部分。**编辑储蓄罐** 可修改名称、货币和投资组合相关开关。**删除储蓄罐** 在确认后删除该储蓄罐及其持仓。

**持仓。** 每项持仓显示名称、以储蓄罐货币计的价值、跟踪方式（*手动*、*钱包* 或 *券商账户*）、原币数量、数值的观测时间和最近一次获取时间。**编辑/移动** 可修改持仓或将其移到另一个储蓄罐；**删除** 会将其移除。

**添加持仓** 会打开持仓编辑器：

- **手动**：名称、货币或资产代码以及数量。适用于应用无法读取的任何资产。
- **钱包**：选择区块链（BTC、ETH、TON、TRX）并粘贴一个公开地址。刷新时，应用会读取原生余额；在 ETH、TON 和 TRX 上，还会读取该地址上的同质化代币。再次打开编辑器并点击 **获取代币**，即可查看这些代币，并关闭您不想计入的代币。
- **券商账户**：选择在[券商]({{ page.base }}/screens/brokers)页面中添加的账户之一；名称留空则使用账户名称。刷新时，应用会读取该账户以账户基础货币计的总价值。一个账户只能关联到一个储蓄罐；删除该持仓只会取消关联，不会删除账户。

**代币与“不计入”。** 代币通过合约地址识别。只有当您的价格数据源列出了这个确切的合约时，该代币才会计入；否则它会显示为 *未知代币 · 不计入*，不计入总额。正是这一点，才让空投来的假“USDT”不会混进您的储蓄。

**投资 PnL。** 在 **编辑储蓄罐** 中开启（复选框 **投资 PnL（损益）**）。之后每次刷新时，应用都会记录每项持仓的数量，以及其券商账户的存入和取出；界面会增加 **投资** 部分：

- 五行：**全部时间**、**近一年**、**近一个月**、**近一周** 和 **近一天**，每行以储蓄罐货币显示损益，并以百分比显示时间加权收益率；为正时显示绿色，为负时显示红色。如果历史记录在该时间段开始之后才开始，该行改为显示 *自 <日期> 起*。
- 储蓄罐价值的 **价值** 图表和累计结果的 **损益** 图表，均以储蓄罐货币计。**全部**、**1Y**、**1M**、**1W** 和 **1D** 按钮会将两张图表聚焦到相应的时间范围；PnL 曲线在该范围的起点从零重新开始。
- *自 <日期> 起 · 以 <货币> 计* 说明历史记录从何时开始。当汇率历史存在空缺时，会显示 *部分日期缺少汇率；这些日期的价值沿用最近一次已知的汇率*。

**计算方式。** 损益 = 价值变化 − 存入 + 取出。百分比按时间加权：逐日收益率连乘，因此存入的时间不会改变它。对于已关联的账户，存入和取出来自券商（[哪些券商]({{ page.base }}/accounts#pnl)）；对于手动持仓和钱包，数量的变化按当日汇率计为存入或取出，绝不计为收益。过去的价值使用每日汇率历史（**设置 → 汇率历史**）。开启开关后，会根据文件夹中已有的快照和券商数据生成历史记录（*正在生成 PnL 历史记录…*，然后是 *PnL 历史记录已就绪：N 天*）；在首次刷新之前，该部分显示 *暂无历史记录*。

**投资组合模式。** 开启后，界面会增加一个表格，列出每项资产的价值、实际占比、目标占比和差额，并提供 **再平衡** 按钮：输入金额后，它会列出需要买入的内容。只有开启 *再平衡时允许卖出* 时才会出现卖出项。不会进行任何交易。
