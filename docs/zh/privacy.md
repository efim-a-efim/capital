# 隐私政策

<p class="meta">Capital for Android（软件包 <code>dev.capital</code>）· 开发者：{{ site.developer }} · 生效日期：2026年9月30日</p>

## 概要

- Capital 没有用户账号、没有数据分析、没有广告、没有崩溃报告，开发者也不运营任何服务器。开发者永远不会收到您的数据。
- 您的财务记录仅存储在您的设备上、您选择的文件夹中。您可以用密码对其加密。
- 唯一的网络流量来自应用根据您的指示，向您在“设置”中选择的价格和区块链数据运营方，以及向您所连接账户的券商发出的请求。这些请求包含您跟踪的钱包公开地址、代币合约和货币代码，以及您为该运营方填写的 API 密钥（如有）；对于券商账户，还包括您创建的访问令牌以及账户 ID 或查询 ID。

## 应用在您设备上存储的内容

**在您选择的文件夹中。** 储蓄罐、持仓、钱包地址、目标、关联、计划储蓄、缓存的价格以及与这些数据相关的设置。除非您开启加密（设置 → 安全），否则文件为明文。开启加密后，每个文件都使用 AES-256-GCM 加密，密钥通过 Argon2id 从您的密码派生。无法找回密码。

**在应用私有存储中**（其他应用无法访问）：

| 项目 | 用途 |
|---|---|
| 对所选文件夹的访问授权 | 下次启动时重新打开该文件夹 |
| 您填写的数据源 API 密钥和券商访问令牌 | 仅发送给签发它们的运营方或券商；使用 Android Keystore 中保存的密钥加密；不包含在快照、导出文件和系统备份中 |
| 锁定设置 | 无需密码即可解锁已加密的文件夹：数据密钥的副本，使用从您的 PIN 派生并绑定到 Android Keystore 的密钥加密。PIN 本身不会被存储 |
| 语言和主题选择 | 界面偏好 |

本应用已禁用 Android 备份和设备间传输，因此系统不会将上述任何内容复制到 Google 或其他设备。

## 哪些数据会离开您的设备

Capital 只联系您在“设置”中选择的运营方，只使用 HTTPS，并且只在您刷新或测试数据源时联系。每个请求得到响应后即被丢弃；应用会将返回的余额和价格保存在您的文件夹中，但不保存请求本身。

| 发送的数据 | 接收方 | 原因 |
|---|---|---|
| 您添加的钱包公开地址 | 为该区块链选择的区块链数据运营方 | 读取该地址的余额和代币持仓 |
| 代币合约地址和资产 ID | 您选择的加密货币价格运营方 | 为资产定价 |
| 货币代码 | 您选择的法定货币汇率运营方 | 在不同货币之间换算 |
| 您为某个运营方填写的 API 密钥 | 仅限该运营方 | 用您自己在该运营方的账号进行身份验证 |
| 券商账户的访问令牌或 API 密钥，以及账户 ID 或查询 ID | 仅限该券商（Interactive Brokers、OANDA、Trading 212 或 SnapTrade） | 读取账户的总价值 |

与任何互联网请求一样，每个运营方也能看到您的 IP 地址。这些运营方独立于开发者，按照各自的条款和隐私政策处理请求，相关链接可在应用的“设置 → 数据来源/署名”中找到：

| 数据 | 运营方 |
|---|---|
| 比特币 | [Blockstream](https://blockstream.info)、[mempool.space](https://mempool.space) |
| 以太坊和 ERC-20 代币 | [PublicNode](https://publicnode.com)、[Alchemy](https://www.alchemy.com)、[Blockscout](https://www.blockscout.com)、[Ethplorer](https://ethplorer.io) |
| TON 和 jetton | [TON Center](https://toncenter.com)、[TonAPI](https://tonapi.io) |
| TRON 和 TRC-20 代币 | [TronGrid](https://www.trongrid.io)、[PublicNode](https://publicnode.com) |
| 加密货币价格 | [DefiLlama](https://defillama.com)、[CoinGecko](https://www.coingecko.com)、[CoinPaprika](https://coinpaprika.com) |
| 法定货币汇率 | [Frankfurter](https://frankfurter.dev)、[欧洲中央银行](https://www.ecb.europa.eu) |
| 券商账户 | [Interactive Brokers](https://www.interactivebrokers.com)、[OANDA](https://www.oanda.com)、[Trading 212](https://www.trading212.com)、[SnapTrade](https://snaptrade.com) |

数据不会发送到其他任何地方。数据不会被出售，不会为广告目的而共享，也不会用于建立用户画像。公开的区块链查询会暴露出：使用您 IP 地址的某个人对您跟踪的地址感兴趣；如果您介意，请使用 VPN。

## 应用绝不会做的事

- 绝不会索取、存储或传输私钥或助记词。它无法签署或发送交易。
- 绝不会转移资金。目标分配只是显示给您的计算结果，仅此而已。
- 绝不会向券商发送订单或任何指令。券商访问权限只用于读取账户价值；参见[券商和外汇账户]({{ page.base }}/accounts)。
- 绝不会联系开发者。没有遥测，应用内没有更新检查，也没有推送通知。

## 权限

| 权限 | 用途 |
|---|---|
| 互联网 | 向上述运营方发出请求 |
| 文件夹访问 | 由您通过 Android 文件夹选择器为所选文件夹授予；应用无法读取其他文件夹 |
| 生物识别 | 通过 Android 自带的提示使用指纹或面部解锁；应用只会收到成功或失败的结果，绝不会收到生物识别数据 |

## 同步和备份

Capital 本身不同步任何内容。如果您用同步工具（Syncthing、Nextcloud、Google Drive……）同步该文件夹，该工具制作的副本适用其自身的隐私条款。除非开启加密，否则文件为明文；在您开启加密之前产生的明文副本，任何持有者都可以读取。

“设置”中的**导出备份**会把单个文件写入您选择的位置。该文件包含相同的记录，其安全程度取决于该位置的安全程度。

## 删除您的数据

删除您选择的文件夹（以及同步工具制作的所有副本），然后卸载应用。卸载会清除应用私有存储，包括数据源密钥和锁定设置。开发者不持有任何需要删除的数据，也无法代您删除任何内容。您查询过的运营方可能会按照各自的保留规则保存请求日志。

## 捐赠 {#donations}

应用（“概览”页上的心形按钮）和本网站会显示开发者的钱包地址，用于自愿打赏。打赏是您从自己的钱包向其中某个地址进行的转账，适用您所用钱包和网络的条款。Capital 不参与其中：它不处理任何付款，无法看到您是否发送了款项，不记录与之相关的任何信息，也不会因此改变任何内容——不会解锁或更改任何功能。打赏的唯一目的是支持开发者。与任何区块链交易一样，向公开地址转账会在该网络上公开您的发送地址。

## 儿童

Capital 是面向成年人的个人理财工具。它不以 13 岁以下儿童为对象，也不会在知情的情况下收集他们的任何数据。
