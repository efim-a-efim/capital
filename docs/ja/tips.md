# 開発者にチップを送る

開発者にチップを送りたい場合は、以下のいずれかの方法をご利用ください。アプリの機能は何も変わりませんが、開発者の支えになります。

{% include tips.html %}

チップとは、あなた自身のウォレットから開発者のアドレスへの送金です。アプリとこのサイトはこれに一切関与せず、送金を確認することもできません。何かが解放されたり、記録されたり、変更されたりすることはありません。同じアドレスは、アプリの「概要」にあるハートボタンからも表示できます。プライバシーポリシーの[寄付]({{ page.base }}/privacy#donations)も参照してください。
