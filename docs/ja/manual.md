# ユーザーマニュアル

<p class="meta">Capital 2.2 · Android 8.0以降</p>

## 基本的な考え方

お金はいくつかの場所に分かれています。預金口座、現金、証券口座、暗号資産ウォレットなど。Capitalでは、それぞれの置き場所を**ポケット**と呼びます。そのお金は、生活防衛資金、旅行、ノートパソコンなど、いくつかの用途のためのものです。Capitalでは、それぞれの用途を**目標**と呼びます。ポケットを目標に接続すると、今あるお金で各目標がどこまで賄えているかをアプリが計算します。さらに貯める**予定**の金額を追加すると、各目標の達成日もわかります。

アプリがお金を動かすことは一切ありません。Capitalは、持っている資産を映す鏡であり、それで何を賄えるかを計算する電卓です。

## 初回起動 {#first-launch}

1. **フォルダを選択します。** 端末上の専用フォルダ（例：`Documents/Capital`）を選んでください。すべての記録はここに書き込まれます。Capitalのデータがすでに入っているフォルダは、そのまま開きます。
2. **設定 → デフォルト通貨。** 合計額と「概要」はこの通貨で表示されます。
3. 必要に応じて、無料のキーで利用上限が上がる事業者（Alchemy、TronGrid、TON Center、CoinGecko）の**プロバイダキー**を「設定」で入力します。すべてのチェーンと価格の取得元には、キー不要のデフォルトがあります。ブローカー口座には、ブローカーが発行する**アクセストークン**が必要で、ブローカータブで入力します。[ブローカー・FX口座]({{ page.base }}/accounts)を参照してください。

## ポケット {#buckets}

「ポケット」タブ → **+**。ポケットに名前と通貨を設定します。ポケットを開いて保有資産を追加します。

- **手動の保有資産**：名前、通貨または資産コード（EUR、USD、BTC、自分で評価する株式のティッカーなど）、数量。銀行残高や現金など、アプリが読み取れないものに使います。
- **ウォレットの保有資産**：チェーン（BTC、ETH、TON、TRX）を選び、公開アドレスを1つ貼り付けます。更新時にアプリはネイティブ残高を読み取り、ETH、TON、TRXではそのアドレスにある代替可能トークンも読み取ります。
- **ブローカー口座**：ブローカータブで追加した口座の1つを選びます。更新時にアプリは、その口座の基準通貨での評価額の合計を読み取ります。1つの口座は1つのポケットにのみ紐づけられます。

金額には小数点としてピリオドまたはカンマを使えます。桁区切りは使えません。各ポケットには、元の資産単位での数量と、デフォルト通貨での評価額が表示されます。レートがない場合、合計は不完全と表示されます。キャッシュされた古い値は警告付きで引き続き使えます。

**トークン。** トークンは名前ではなく、必ずコントラクトアドレスで識別されます。選択した価格の取得元がそのコントラクトを掲載している場合にのみ集計され、それ以外は *不明なトークン · 集計対象外* と表示されて合計に含まれません。ウォレットの保有資産の編集画面を開くと、トークンを取得して、不要なものをオフにできます。

**ポートフォリオモード**（ポケットの設定）は、ポケットを投資ポートフォリオとして扱います。資産ごとに目標配分を設定し、目標に対する実際の構成比を確認し、**リバランス**で指定した金額に対して何を購入すべきかの一覧を得られます。売却が提案されるのは、*リバランス時に売却を許可* がオンの場合のみです。これは計算機であり、何も変更しません。

## 投資PnL {#pnl}

ポケットの編集画面で **投資PnL** をオンにすると、入金分を除いたポケットの運用成果を確認できます。ポケットの画面に、全期間・過去1年・1か月・1週間・1日の損益と時間加重収益率、評価額チャート、損益チャート（期間チップ：全期間、1Y、1M、1W、1D）が表示されます。

- **データ。** 更新のたびにポケット内の各保有資産の数量を記録し、紐づけたブローカーに入出金を問い合わせます。手動またはウォレットの数量の変化は、その日のレートでの入金または出金として扱われます。過去の評価額には、日次の[レート履歴]({{ page.base }}/screens/settings)を使います。
- **過去分の作成。** オンにすると、フォルダ内のスナップショット（1日につき1つ）から履歴を作り直し、足りないレートを取得し、各ブローカーに入出金の履歴と、提供されている場合は日次の口座評価額を問い合わせます。どのブローカーが何を提供するかは、[ブローカーのページ]({{ page.base }}/accounts#pnl)にまとめています。
- **見方。** 損益は評価額の変動から純入金額を引いたものです。パーセンテージは時間加重のため、入金のタイミングに左右されません。期間の開始が履歴より前の場合は、数値の代わりに *<日付> 以降* と表示されます。

## 目標 {#goals}

「目標」タブ → **+**。目標には名前、通貨、目標金額、期限があります。目標を開いて **ポケットを接続** し、どのポケットから資金を充てるかを指定します。上限も任意で設定できます：固定額、ポケットに対する割合、目標に対する割合のいずれかです。

お金の配分方法：

- 期限の早い目標から先に資金が充てられます。同じ期限の目標は表示順に充てられます。ハンドルをドラッグして並べ替えます。
- 複数の目標に接続されたポケットは、上限に従って目標間で分けられ、二重に数えられることはありません。
- 結果は *配分額／目標金額* と *不足額* で表示されます。「概要」では、合計、目標に配分済みの額、残りの額を確認できます。

**バッジ。** 今ある貯蓄ですでに目標を賄えている場合は *達成済み*（緑）。貯蓄予定によって期限日までに達成できる場合は *期限内に達成見込み*（緑）。それ以外は *未達成*（黄）。目標の下の文には、いつ達成するか、またはいくら不足するかが表示されます。

目標を **アーカイブ** すると、集計せずに保持できます。アーカイブ済みの目標は一番下に表示されます。

## FIRE {#fire}

種類が **FIRE** の目標は、貯蓄がいつから生活費をまかない始められるか、そしてそれがどれだけ持つかを示します。ご自身の数値に基づく計算であり、何かを推奨するものではありません。画面については [目標]({{ page.base }}/screens/goal#fire) で説明しています。

**設定方法。**

1. 「目標」タブ → **+**。**目標の種類** を **FIRE** にし、名前と通貨を設定します。
2. 分かっていることを現在の価値で入力します：**生年月日**、**FIRE日**、**投資できる額**（週、2週間、月、年、またはN日ごと）、**積立額の年間増加率 %**（投資できる額の毎年の増額分。空欄 = インフレ率）、**FIRE後の月々の支出**、**FIRE後に必要な金額**。アプリに算出させたい項目は空欄のままにします。
3. 目標を開き、すでにある貯蓄について、他の目標と同様に **ポケットを接続** します。

**見方。** 表には **平均**、**楽観**、**悲観** の3列があり、成長率とインフレ率の3通りの組み合わせに対応します。FIRE日を空欄にすると、各シナリオは、支出が想定寿命まで持つ最初の日付をFIRE日として算出し、シナリオの見出しに表示します。**お金が持つ期間** は、お金が支出をいつの日付まで、何歳までまかなえるかを示します。*想定寿命を超えて持続* と *お金は尽きません 🥳* は良いケースで、*… 不足* はその日付に到達できないことを意味します。グラフは現在の価値で表したお金を示し、破線のFIRE日まで増え、それ以降は減っていきます。3本の曲線は予測ではなく、幅のある範囲として受け止めてください。**今使える額 · 月** と **· 年** は、今取り崩せる額を示します。FIRE日より前は0で、その後は目標が現在持っているお金を最新の価格で評価した額を、想定寿命まで均等に配分した額です。市場が下がると、お金とともに下がります。

**前提。** 支出は購買力を保ちます（インフレに合わせて増えます）。積立額は独自の年間増加率で増え、空欄の場合はインフレに合わせて増えます。税金、年金、給付金、FIRE後の収入はモデルに含まれません。初期値：成長率7 %（楽観10 %、悲観4 %）、インフレ率3 %（2 %、5 %）、取り崩し率4 %、就労を続ける年齢65歳（算出されるFIRE日はそれより先を探しません）、想定寿命95歳。いずれも **詳細な前提条件** で変更でき、入力した値が常に優先されます。

**初期値の出典。** UBS Global Investment Returns Yearbook 2026（世界、1900〜2024年：株式は名目で年9.8 %、債券は4.6 %、インフレ率は2.9 %。7 %は株式6割・債券4割の組み合わせにほぼ相当）、中央銀行の2 %のインフレ目標、そして4 %の取り崩しルールについてはBengen（1994年）とTrinity study（1998年）。

**最新のレート。** 設定 → 無料データプロバイダ → **インフレ率**（**World Bank**、**ECB**、**OECD**、**オフ**）と **市場成長率**（**World Bank**、**Yahoo Finance · 非公式**、**オフ**）。**更新** は、すべてのFIRE目標の通貨についてこれらを取得します。インフレ率：World Bankの消費者物価（年次、国別または世界平均）、ECBのユーロ圏HICP（EURのみ）、OECD（加盟国。RUBは対象外）。成長率：国別のWorld BankのS&P Global株価指数の変化率（EURは米国の指数を使用）、またはYahoo Financeの非公式エンドポイントから取得した30年分の月次終値（^GSPC、^GDAXI、^FTSE、^N225、^BSESN、^BVSP、000001.SS。その他の通貨は^GSPCを使用）。これらの系列から：平均インフレ率は直近20年の平均、楽観と悲観は5年平均の最低値と最高値。平均成長率は最大30年間の年平均複利、楽観と悲観は10年間の年率の最良値と最悪値です。成長率の取得元はどちらも配当を含まない価格指数のため、トータルリターンを過小に見積もります。**オフ** にすると組み込みの初期値が使われます。取得に失敗した場合は、前の系列を保持し、エラーを表示します。

## 貯蓄予定 {#plans}

「貯蓄予定」タブ → **+**。貯蓄予定とは、ある日付に追加するつもりの金額です。たとえば毎月末の給料からの貯金などです。貯蓄予定は貯蓄には含まれず、予測を延長するだけです：「貯蓄予定により 2026年10月30日 に目標達成の見込み · 期限内」。

貯蓄予定のお金は、今あるポケットの後に、期限の順で目標に充てられます。そのため、まだ不足している分を補うだけです。貯蓄予定の日付が過ぎると **アーカイブ済み** セクションに移り、集計されなくなります。すでにそのお金をポケットに移していてアプリがそこで把握しているか、予定が実現しなかったかのどちらかです。再び有効にするには日付を未来に変更してください。不要になった場合は削除します。

## ブローカー

ブローカータブ → **+**。ブローカー口座は読み取り専用の接続です。ブローカー（一覧は[ブローカー・FX口座]({{ page.base }}/accounts)にあります）を選び、口座IDまたはクエリIDを入力して保存します。ブローカーのトークンやキーは、同じタブの **認証情報** で一度だけ入力すれば、そのブローカーのすべての口座に使われます。タブには各口座の最後の評価額と、紐づけ先のポケットが一覧表示されます。**次の金額未満の残高を無視**に既定の通貨で金額（初期値は1）を設定すると、少額の残高はポケットで0として集計されます。**保有資産を追加 → ブローカー口座** でポケットに紐づけます。保有資産を削除すると紐づけが解除され、口座を削除すると接続が削除されます。セットアップの手順と各ブローカーの公式ドキュメントへのリンクは、[ブローカー・FX口座]({{ page.base }}/accounts)にあります。

## 更新

上部の更新アイコンで、すべてのウォレット残高、ブローカー口座の評価額、価格を再読み込みします。ポケットは個別に更新することもできます。アプリはコールドスタート時に一度だけ更新します。バックグラウンドから戻ったときは、ローカルファイルを再読み込みするだけです。更新にはインターネット接続が必要です。接続がない場合は以前の値が残り、古い値として表示されます。更新のたびにその日のレートもレート履歴に記録されます。**設定 → レートの自動更新** を使うと、この履歴がバックグラウンドで（1〜24時間ごとに）最新の状態に保たれ、アプリを開いたときに最新のレートが使われます。

## セキュリティ {#security}

設定 → セキュリティ。

- **暗号化** は、以前のリビジョンも含め、フォルダ内のすべてのファイルをパスワードで暗号化します。オフにすると復号されます。**パスワードは復旧できません**。パスワードを紛失すると、データは二度と開けなくなります。暗号化をオンにする前に作成した暗号化なしのバックアップは読み取り可能なままです。アプリは警告を表示しますが、それらを削除することはできません。
- **PIN** と **生体認証** は、暗号化がオンのときに利用できます。PIN画面では常に *パスワードを使用* を選べます。PINを10回間違えるとPINは削除され、パスワードでしかロックを解除できなくなります。入力を間違えてもデータが削除されることはありません。
- 暗号化がオンの間は、スクリーンショットと最近使ったアプリのプレビューがブロックされます。

## 同期、バックアップ、復旧 {#sync-backup-recovery}

CapitalはリビジョンIDとチェックサム付きのスナップショットファイルをフォルダに書き込み、独自の同期は一切行いません。普段お使いの同期ツールでフォルダを同期してください。2台の端末で同時に編集した場合、アプリは競合画面を表示してバージョンを選択させます。元のファイルは両方ともディスクに残ります。

- **バックアップをエクスポート**（設定）は、持ち運び可能なファイルを1つ書き出します。**復元** は、何かを変更する前にファイルを検証します。
- 保存に失敗した場合、編集内容はメモリに保持され、*保存を再試行* と *フォルダにコピーを保存* を選べます。
- フォルダへのアクセス権が失われた場合は、同じフォルダを再接続してください。
- 新しいバージョンのアプリが書き込んだファイルは、古いバージョンでは開けません。アプリを更新してください。

## 言語 {#language}

端末の言語が対応する15言語のいずれかであれば、アプリはその言語で起動します。それ以外の場合は英語で起動します。設定 → 言語 で変更できます。

## Google Play 以外からのインストール

[最新リリース]({{ site.repo }}/releases/latest) からAPKをダウンロードして開きます。Androidから確認されたら、その提供元からのインストールを許可してください。すべてのリリースは同じ鍵で署名されているため、新しいバージョンを古いバージョンの上からインストールでき、設定も引き継がれます。データが入ったフォルダは、アップデートやアンインストールで変更されることはありません。
