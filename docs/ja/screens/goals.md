# 目標

**この画面について。** 貯蓄の目的すべてを、期限ごとにまとめ、お金が割り当てられる順に表示します。

**各カードの表示内容。**

- 名前とバッジ：今ある貯蓄で目標金額を賄えている場合は **達成済み**（緑）、貯蓄予定によって期限までに達成できる場合は **期限内に達成見込み**（緑）、それ以外は **未達成**（黄）。
- 目標の通貨での **配分額／目標金額** と期限。
- 進捗バー。濃い部分は今日時点で賄えている額、薄い部分は貯蓄予定で後から加わる額です。
- バーの下の行：*現時点で達成済み*、貯蓄予定によって目標を達成する日付、またはいつまでにいくら不足するか。

**並び順と優先順位。** 期限の早い目標から先に資金が充てられます。同じ期限の目標は表示順に充てられます。**≡** ハンドルをドラッグして順序を変更します。アーカイブ済みの目標は一番下に置かれ、資金は割り当てられません。

**目標の追加。** **+** を押します。目標には名前、通貨、目標金額、期限があります。目標を開いてポケットを1つ以上接続するまで、目標にお金は割り当てられません。[目標]({{ page.base }}/screens/goal) を参照してください。

**配分の仕組み。** ポケットは、各接続に設定された上限の範囲内で、接続先の目標の間で分け合われ、期限の早い目標が優先されます。1つのポケットが複数の目標に接続されている場合、ある目標が不足したまま別の目標が過剰に賄われることがないよう、アプリは目標間でお金を割り当て直します。貯蓄予定は実際のすべてのポケットの後にだけ充てられるため、すでにあるお金の代わりになることはありません。
