# 設定

**この画面について。** 記録以外のすべて：環境設定、データの取得元、セキュリティ、フォルダ。上部バーの歯車アイコンで開きます。画面幅の広い端末では、ナビゲーションレールのタブになります。

**お知らせ。** 上部の黄色のバーは、キャッシュされた値が古いとき（オンライン時に更新してください）、または残高やレートを取得できず評価が不完全なときに表示されます。この画面にだけ表示されます。

**環境設定。** デフォルト通貨とテーマ（システム、ライト、ダーク）。デフォルト通貨は「概要」の評価に使われ、新しいポケットや目標にも提案されます。既存の記録の通貨は変わりません。**言語** はインターフェースを即座に切り替えます。*システムのデフォルト* は端末の設定に従います。

**無料データプロバイダ。** データの種類ごとに1行ずつ、使用中の事業者が表示されます：BTC、ETH、TON、TRXの残高、ETH、TON、TRXのトークン一覧、暗号資産の価格、法定通貨のレート、**インフレ率**（**World Bank**、**ECB**、**OECD**、**オフ**）、**市場成長率**（**World Bank**、**Yahoo Finance · 非公式**、**オフ**）。この2つは [FIRE目標]({{ page.base }}/screens/goal#fire) で使われ、**オフ** のときは組み込みの初期値が使われます。**レート履歴**（**Frankfurter + DefiLlama**、**オフ**）は、保有するすべての資産の日次レート履歴を記録の最も古い日付まで遡って埋め、過去の評価額を計算できるようにします。行をタップすると、別の事業者を選んだり、チェーンのトークン照会を **オフ** にしたり、任意のAPIキーを入力したりできます。キーは端末に暗号化して保存され、発行元の事業者にのみ送信されます。**取得元をテスト／ポートフォリオを更新** は、実際に保有している資産ですべての事業者に問い合わせ、失敗したものを報告します。事業者が黙って別のものに置き換えられることはありません。

**ブローカー。** ブローカー口座とその認証情報は専用の画面にあります：[ブローカー]({{ page.base }}/screens/brokers)。

**レートの自動更新。** **オフ**、**24時間ごと**、**12時間ごと**、**6時間ごと**、**3時間ごと**、**1時間ごと**。オンにすると、バックグラウンドの処理がこの間隔で、上で選んだ事業者を使って保有するすべての資産の現在のレートを取得し、サンプルをレート履歴に保存します。データフォルダには一切触れません。次にアプリを開いたとき、または更新したときに、サンプルがキャッシュされたレートに統合されるため、オフラインでも合計は最新のレートから始まります。ネットワーク接続が必要で、バッテリーとデータ通信を少し使います。最後の実行は **レートと更新状況** の下に *最終バックグラウンド更新* として表示されます。

**レートと更新状況。** キャッシュされたすべてのレートと、取得したすべてのインフレ率・成長率の系列について、取得元と、その観測日時と取得日時。古いレートも引き続き使用でき、この画面上部のお知らせで古い値として示されます。

**セキュリティ。** **暗号化** は、フォルダ内のすべてのファイルをパスワードで暗号化します。オフにすると復号されます。暗号化がオンのときは、**PINを設定**、**生体認証を使用** の有効化、**バックグラウンドでロックするまでの時間** の選択、**パスワードを変更** ができます。パスワードは復旧できません。PINを10回間違えるとPINは削除されます。パスワードは常に使えます。[セキュリティ]({{ page.base }}/manual#security) を参照してください。

**ストレージ。** 現在のフォルダとそのリビジョン。**フォルダを再接続／開く** はフォルダ選択画面を再度開きます。**ローカルファイルを再読み込み** は、同期ツールが変更を届けた後などにフォルダを読み込み直します。**バックアップをエクスポート** は、持ち運び可能なファイルを1つ書き出します（暗号化がオフの場合は暗号化なしで、その旨が表示されます）。**バックアップを復元** は、記録を置き換える前にファイルを検証し、既存のスナップショットを保持します。

**取得元／クレジット。** すべての事業者のサイトへのリンク。

**法的情報。** このサイトの[プライバシーポリシー]({{ page.base }}/privacy)、[データ セーフティ]({{ page.base }}/data-safety)、[金融機能]({{ page.base }}/financial-features)の宣言へのリンク（インターフェース言語）。アプリのバージョンとビルド番号は一番下にあります。
