# ポケット

**この画面について。** お金を置いている場所の一覧です。ポケットには、銀行口座、手元の現金、証券口座、取引所のアカウント、暗号資産ウォレットなどが使えます。

**各カードの表示内容。** ポケットの名前、ポケット自身の通貨での評価額、保有資産の件数。カードをタップすると [ポケット]({{ page.base }}/screens/bucket) が開きます。

**ポケットの追加。** 右下の **+** を押します。ポケットには名前と通貨が必要です。通貨にはEURやUSDなどのISOコード、またはBTCなどのネイティブ資産を指定します。通貨はポケットの合計の表示方法を決めるだけで、中の保有資産はどの通貨でもかまいません。

**ポートフォリオモード。** 同じ編集画面に *ポートフォリオモード* のスイッチがあります。ポートフォリオのポケットでは、各資産の実際の構成比が、設定した目標配分と並べて表示され、リバランス計算機が使えます。[ポートフォリオモード]({{ page.base }}/manual#buckets) を参照してください。

**並び順。** ポケットは作成順に表示されます。並び順は配分に影響しません。

**更新。** 上部バーの更新で、すべてのポケットを再読み込みします。個別のポケットは、そのポケットの画面から更新できます。
