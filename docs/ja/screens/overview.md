# 概要

**この画面について。** ホームタブです。保有するすべての資産の合計、そのうち目標に割り当てられている額、各目標の状態を表示します。

**表示内容。**

- **貯蓄の評価額合計**（デフォルト通貨建て）：すべてのポケットのすべての保有資産を、最新のレートで換算したもの。レートがない場合は合計が不完全と表示されますが、元の資産単位での数量は「ポケット」タブで引き続き確認できます。
- **目標に配分済み**：合計のうち、目標が接続を通じて割り当てを受けられる部分。
- **未配分**：どの目標にも割り当てられていない部分。そのポケットにどの目標も接続されていない、接続の上限で制限されている、接続されたすべての目標がすでに達成済みである、といった理由で未配分になります。
- **あなたの目標**：「目標」タブと同じカードが、資金が充てられる順に、バッジと予測の行付きで表示されます。

**数値の関係。** 合計 = 配分済み + 未配分。これは常に成り立ちます。配分でお金が移動することはありません。どのポケットが今日時点でどの目標を賄うかを示すだけです。

**上部バー。** 更新アイコンは、すべてのウォレット残高と価格を再読み込みし、処理中は回転します。歯車アイコンで「設定」が開きます。**?** でこのページが開きます。

**お知らせ。** レートが古いか取得できていない場合、フォルダに未保存の変更がある場合、フォルダの2つのリビジョンが競合している場合に、黄色のバーが表示されます。各お知らせには専用のボタンがあります。[同期、バックアップ、復旧]({{ page.base }}/manual#sync-backup-recovery) を参照してください。
