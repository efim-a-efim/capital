# ポケット

**この画面について。** 1つのポケットとその保有資産です。[ポケット]({{ page.base }}/screens/buckets) タブでカードをタップすると開き、**← すべてのポケット** で戻ります。

**ヘッダー。** ポケットの評価額と、2つ一組で意味を持つ数値：接続された目標に割り当てられた **配分済み** と、残りの **配分可能**。**ポケットを編集** で名前、通貨、ポートフォリオのスイッチを変更します。**ポケットを削除** は、確認の後にポケットとその保有資産を削除します。

**保有資産。** 各保有資産には、名前、ポケットの通貨での評価額、追跡方法（*手動*、*ウォレット* または *ブローカー口座*）、元の資産単位での数量、評価額の観測日時と最終取得日時が表示されます。**編集／移動** で内容を変更したり別のポケットに移動したりでき、**削除** で削除します。

**保有資産を追加** で保有資産の編集画面が開きます：

- **手動**：名前、通貨または資産コード、数量。アプリが読み取れないものすべてに使います。
- **ウォレット**：チェーン（BTC、ETH、TON、TRX）を選び、公開アドレスを1つ貼り付けます。更新時にアプリはネイティブ残高を読み取り、ETH、TON、TRXではそのアドレスにある代替可能トークンも読み取ります。編集画面を再度開いて **トークンを取得** を押すとトークンが表示され、集計したくないものをオフにできます。
- **ブローカー口座**：[ブローカー]({{ page.base }}/screens/brokers) 画面で追加した口座の1つを選びます。名前を空欄にすると、口座の名前が使われます。更新時にアプリは、その口座の基準通貨での評価額の合計を読み取ります。1つの口座は1つのポケットにのみ紐づけられます。保有資産を削除すると、口座は削除されずに紐づけだけが解除されます。

**トークンと「集計対象外」。** トークンはコントラクトアドレスで識別されます。価格の取得元がそのコントラクトを掲載している場合にのみ集計され、それ以外は *不明なトークン · 集計対象外* として表示されて合計に含まれません。これにより、エアドロップで送られてきた偽の「USDT」が貯蓄に紛れ込むのを防ぎます。

**投資PnL。** **ポケットを編集** で有効にします（チェックボックス **投資PnL**）。以降は更新のたびに、各保有資産の数量とブローカー口座の入出金が記録され、画面に **投資** セクションが加わります：

- **全期間**、**過去1年**、**過去1か月**、**過去1週間**、**過去1日** の5行。それぞれにポケットの通貨での損益と、時間加重収益率（％）が表示されます。プラスは緑、マイナスは赤です。履歴がその期間の開始より後に始まる場合は、代わりに *<日付> 以降* と表示されます。
- ポケットの評価額を示す **評価額** チャートと、累積の結果を示す **損益** チャート（どちらもポケットの通貨）。チップの **全期間**、**1Y**、**1M**、**1W**、**1D** で、両方のチャートをその期間に絞り込めます。PnLの曲線は期間の開始時点で0から始まります。
- *<日付> 以降 · <通貨> 建て* は履歴の開始日を示します。レート履歴に欠けがあると、*レートのない日があります。その日の値には直近のレートを使用しています。* と表示されます。

**計算方法。** 損益 ＝ 評価額の変動 − 入金 ＋ 出金。パーセンテージは時間加重です。毎日の収益率を連鎖させるため、入金のタイミングは結果に影響しません。紐づけた口座の入出金はブローカーから取得します（[対応するブローカー]({{ page.base }}/accounts#pnl)）。手動の保有資産とウォレットでは、数量の変化がその日のレートでの入金または出金として扱われ、利益にはなりません。過去の評価額には日次のレート履歴を使います（**設定 → レート履歴**）。スイッチをオンにすると、フォルダにあるスナップショットとブローカーから履歴が作成されます（*PnL履歴を作成中…*、続いて *PnL履歴の準備ができました：N 日分*）。最初の更新までは、セクションに *履歴はまだありません* と表示されます。

**ポートフォリオモード。** オンにすると、資産ごとの評価額、実際の構成比、目標配分、差分の表と、**リバランス** ボタンが追加されます。このボタンは金額を尋ね、購入すべきものを一覧にします。売却が表示されるのは *リバランス時に売却を許可* がオンの場合のみです。実際の取引は一切行いません。
