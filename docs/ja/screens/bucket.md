# ポケット

**この画面について。** 1つのポケットとその保有資産です。[ポケット]({{ page.base }}/screens/buckets) タブでカードをタップすると開き、**← すべてのポケット** で戻ります。

**ヘッダー。** ポケットの評価額と、2つ一組で意味を持つ数値：接続された目標に割り当てられた **配分済み** と、残りの **配分可能**。**ポケットを編集** で名前、通貨、ポートフォリオのスイッチを変更します。**ポケットを削除** は、確認の後にポケットとその保有資産を削除します。

**保有資産。** 各保有資産には、名前、ポケットの通貨での評価額、追跡方法（*手動* または *ウォレット*）、元の資産単位での数量、評価額の観測日時と最終取得日時が表示されます。**編集／移動** で内容を変更したり別のポケットに移動したりでき、**削除** で削除します。

**保有資産を追加** で保有資産の編集画面が開きます：

- **手動**：名前、通貨または資産コード、数量。アプリが読み取れないものすべてに使います。
- **ウォレット**：チェーン（BTC、ETH、TON、TRX）を選び、公開アドレスを1つ貼り付けます。更新時にアプリはネイティブ残高を読み取り、ETH、TON、TRXではそのアドレスにある代替可能トークンも読み取ります。編集画面を再度開いて **トークンを取得** を押すとトークンが表示され、集計したくないものをオフにできます。

**トークンと「集計対象外」。** トークンはコントラクトアドレスで識別されます。価格の取得元がそのコントラクトを掲載している場合にのみ集計され、それ以外は *不明なトークン · 集計対象外* として表示されて合計に含まれません。これにより、エアドロップで送られてきた偽の「USDT」が貯蓄に紛れ込むのを防ぎます。

**ポートフォリオモード。** オンにすると、資産ごとの評価額、実際の構成比、目標配分、差分の表と、**リバランス** ボタンが追加されます。このボタンは金額を尋ね、購入すべきものを一覧にします。売却が表示されるのは *リバランス時に売却を許可* がオンの場合のみです。実際の取引は一切行いません。
