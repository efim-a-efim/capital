# ブローカー

**この画面について。** 証券口座やFX口座への読み取り専用の接続です。ブローカー口座は、ブローカー、口座ID（またはクエリID）、そしてブローカーの認証情報で構成されます。更新のたびに、アプリはその口座の基準通貨での評価額の合計を読み取ります。口座はポケットの中ではなくこの画面にあり、ポケットは口座に紐づくだけです。貯蓄が集計される場所は、これまでどおりポケットです。

**各行の内容。** 口座の名前、ブローカーとID、口座の通貨と既定の通貨での最後に読み取った評価額、評価額の観測日時と取得日時、そして紐づけ先のポケット。**… に紐づけ済み** をタップするとそのポケットが開き、*ポケットに未紐づけ* は、まだどこにも集計されていないことを示します。**編集** で名前、ブローカー、IDを変更できます。**削除** は口座を削除し、紐づけられていた場合は、それを紐づけていた保有資産も削除します。

**口座を追加する。** **+** を押し、名前を入力し、ブローカーを選び、そのブローカーが使うIDを入力します。Interactive BrokersならFlex Query id、OANDAなら口座ID、Trading 212なら口座番号です。SnapTradeの場合は、**SnapTradeでブローカーを接続** を押し、接続後に戻って **口座を取得** を押し、口座を1つ選びます。保存します。通貨と評価額は、次の更新後に表示されます。

**次の金額未満の残高を無視。** オンにして既定の通貨で金額を入力すると（初期値は1）、少額の残りが貯蓄に混ざるのを防げます。口座の評価額をキャッシュされたレートで換算した値がその金額を下回ると、紐づけられた保有資産は0として集計され、その行に*0として集計：…未満*と表示されます。実際の評価額はこの画面に表示されたままです。口座の通貨のレートがない場合は、何も無視されません。

**ポケットに紐づける。** ポケットを開き、**保有資産を追加** を押し、**追跡方法** を **ブローカー口座** に設定して、口座を選びます。名前を空欄にすると、口座の名前が使われます。1つの口座は同時に1つのポケットにのみ入れられます。保有資産の **編集／移動** で別のポケットに移せます。保有資産を削除すると、口座は削除されずに紐づけだけが解除されます。

**認証情報。** 対応する各ブローカーのトークンまたはキーです。ブローカーごとに1組で、そのブローカーのすべての口座に使われます。Android Keystoreで保持する鍵で暗号化され、データフォルダには書き込まれず、エクスポートやシステムのバックアップにも含まれず、発行元のブローカーにのみ送信されます。**ブローカー口座のセットアップガイド** は [ブローカー・FX口座]({{ page.base }}/accounts) を開き、ブローカーごとの手順を表示します。

**更新。** この画面の更新アイコンはすべての口座を読み取ります。ポケットの更新は、そのポケットに紐づけられた口座だけを読み取ります。読み取れなかった口座は最後の評価額を保持し、その行の下にブローカーからのメッセージが表示されます。アプリは読み取るだけで、注文を出したりお金を動かしたりすることは一切ありません。
