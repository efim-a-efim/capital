# 目標

**この画面について。** 1つの目標とその資金の内訳です。[目標]({{ page.base }}/screens/goals) タブでカードをタップすると開き、**← すべての目標** で戻ります。

**ヘッダー。** 名前とバッジ、配分額／目標金額、期限、予測の行、そして **不足額**（目標金額から今日時点で賄えている額を引いたもの）。

**ボタン。** **目標を編集** で名前、通貨、目標金額、期限を変更します。**アーカイブ** は目標を集計せずに保持します。アーカイブ済みの目標には代わりに **再開** が表示されます。**削除** は、確認の後に目標とその接続を削除します。

## FIRE {#fire}

**目標の種類** が **FIRE**（経済的自立と早期リタイア）の目標は、2つの問いに答えます。いつからお金で生活費をまかなえるか、そしてそのお金がどれだけ持つか。ご自身の数値に基づく試算であり、何かを推奨するものではありません。種類は編集画面の **目標の種類**（**貯蓄目標** ／ **FIRE**）で設定します。

**編集画面の項目。** 名前と通貨以外はすべて空欄にでき、アプリが残りの項目から算出できるものを算出します。

- **生年月日 · YYYY-MM-DD · 任意**：年齢を表示し、期間を想定寿命までとします。
- **FIRE日 · YYYY-MM-DD · 空欄で自動算出**：積み立てをやめて取り崩しを始める日。
- **投資できる額 · 空欄で自動算出**：**週**、**2週間**、**月**、**年**、**N日** ごとの金額（**N日** の場合は **日数** を入力）。
- **積立額の年間増加率 % · 空欄 = インフレ率**：毎年、投資できる額をどれだけ増やせるか（たとえば毎年の昇給）。空欄の場合は積立額の購買力が保たれます。
- **FIRE後の月々の支出 · 空欄で自動算出**。
- **FIRE後に必要な金額 · 空欄で自動算出**：FIRE必要額、つまり目標の目標金額。
- **詳細な前提条件**：**インフレ率 % · 平均 / 楽観 / 悲観**、**成長率 % · 平均 / 楽観 / 悲観**、**取り崩し率 %**、**想定寿命 · 年**。各ラベルの末尾には「· 現在 {値}」が付き、項目が空欄のときに適用される値を示します。

すべての金額は、目標通貨での現在の価値です。画面には、将来の価値で表したFIRE日時点の金額も表示されます。目標が今持っているお金は、他の目標と同様に、接続したポケットから算出されます。[貯蓄予定]({{ page.base }}/screens/plans) はFIRE計算には含まれません。

**算出されるもの。**

- FIRE日：目標金額と積立額から。
- 積立額：目標金額とFIRE日から。
- 目標金額：支出から（支出 × 12 ÷ 取り崩し率）、またはFIRE日と積立額から。
- 支出：目標金額から（目標金額 × 取り崩し率 ÷ 12）。

FIRE日、積立額、目標金額がすべて入力されている場合は、日付はそのまま保持され、画面には不足額と到達可能な最も早い日付が表示されます。算出された目標金額と日付は、目標の目標金額と期限に書き込まれるため、並び順、配分、「概要」、貯蓄予定は他の目標と同じように機能します。これらは編集のたびと更新のたびに再計算されます。

**FIRE欄。** まず、すべてのシナリオで共通の値（入力した内容と **取り崩し率**）が1行に1つずつ表示されます。続いて、シナリオ（**平均**、**楽観**、**悲観**）ごとに折りたためる行があり、成長率とインフレ率、およびバッジが表示されます。バッジは、お金が想定寿命を超えて持つ場合は **お金は足ります**（緑）、お金が尽きない場合は **お金は尽きません 🥳**（緑）、FIRE日に到達できない場合やお金がそれより早く尽きる場合は **お金が足りません**（黄）です。行をタップすると、シナリオごとに異なる値が展開されます。

| 行 | 意味 |
|---|---|
| **FIRE日** | 日付。生年月日が分かっている場合は「N歳」も表示、または *<date> までに到達できません* |
| **月々の積立額** | 毎月投資する必要がある額 |
| **FIRE必要額 · 現在の価値** | 必要な金額（編集画面で指定した額） |
| **FIRE必要額 · FIRE日の価値** | 同じ金額をインフレ後の価値で表したもの |
| **月々の支出 · 現在の価値** | FIRE後の月々の支出 |
| **月々の支出 · FIRE日の価値** | 同じ支出をインフレ後の価値で表したもの |
| **お金が持つ期間** | *<date> まで · N歳*、*N年 · 想定寿命を超えて持続*、*お金は尽きません 🥳*、または日付に到達できない場合は *… 不足* |

折りたたみの下には、レートの取得元のプロバイダ名または *組み込みの初期値* を示す「レート：…」の行があります。その下のグラフは、お金が減っていく様子を示すグラフです。今日からお金が尽きるまで、または期間の終わりまでの、現在の価値で表した金額を、シナリオごとに3本の色付きの曲線で表します。破線はFIRE日を示します。その下の注記は *ご自身の数値に基づく試算です。何かを推奨するものではありません。* です。[目標]({{ page.base }}/screens/goals) タブでは、この目標に *FIRE日 <date> · N歳*、または *到達不可* と表示されます。

**計算方法。** 月単位で計算します。FIRE日までは、積立額は **積立額の年間増加率 %** で増え（空欄の場合はインフレに合わせて増えるため、購買力が保たれます）、お金はシナリオのレートで増えます。FIRE日以降は、支出がインフレに合わせて増え、残ったお金はシナリオのレートで増え続けます。期間は、生年月日に想定寿命（初期値は95）を足した日まで、生年月日がない場合はFIRE日から50年後までです。*お金は尽きません* とは、200年たってもお金が尽きず、最後の時点の現在の価値がFIRE日時点以上であることを意味します。

**初期値と出典。** 上書きも取得したレートもない場合、アプリは成長率7 %（楽観10 %、悲観4 %）、インフレ率3 %（2 %、5 %）、取り崩し率4 %を使います。出典は、UBS Global Investment Returns Yearbook 2026（世界、1900〜2024年：株式は名目で年9.8 %、債券は4.6 %、インフレ率は2.9 %。7 %は株式6割・債券4割の組み合わせにほぼ相当）、中央銀行の2 %のインフレ目標、そして4 %ルールについてはBengen（1994年）とTrinity study（1998年）です。マニュアルの [FIRE]({{ page.base }}/manual#fire) も参照してください。

**最新のレート。** **更新** は、すべてのFIRE目標の通貨について、[設定]({{ page.base }}/screens/settings) で選んだプロバイダからインフレ率と市場成長率を取得します。優先順位は、**詳細な前提条件** での上書き、取得した値、初期値の順です。取得に失敗した場合は、前の系列を保持し、エラーを表示します。2つの成長率の取得元はどちらも配当を含まない価格指数のため、トータルリターンを過小に見積もります。

**メッセージ。**

| メッセージ | 対処 |
|---|---|
| *目標金額、月々の支出、またはFIRE日と積立額の両方を入力してください* | 3つのうちいずれかを入力します。入力がないと何も算出できません。 |
| *FIRE日または積立額を入力してください* | 目標金額は分かっていますが、日付も積立額もありません。どちらか一方を入力します。 |
| *FIRE日が過去の日付です* | 将来の日付を選びます。 |
| *生年月日が未来の日付です* | 生年月日を修正します。 |
| *取り崩し率は0より大きくしてください* | **詳細な前提条件** で0より大きい取り崩し率を入力するか、空欄にして初期値を使います。 |
| *<date> までに到達できません* | この積立額とレートでは、その日付（期間の終わり）までに目標金額に届きません。積立額を増やすか、目標金額や支出を減らすか、別のシナリオを選びます。 |
| *<currency> のレートデータがありません* | インフレ率または成長率のプロバイダに、この通貨の系列がありません。別のプロバイダを選ぶか、**詳細な前提条件** でレートを入力します。 |
| *ECBは <currency> に対応していません* | ECBが提供するのはユーロ圏のインフレ率のみです。設定で別の **インフレ率** プロバイダを選びます。 |
| *OECDは <currency> に対応していません* | OECDにはこの通貨（たとえばRUB）の系列がありません。設定で別の **インフレ率** プロバイダを選びます。 |

**資金源。** この目標に資金を充てられるポケットです。**ポケットを接続** で、充当額の上限を付けてポケットを追加します：

- **自動 — 不足額まで**：先に並ぶ目標が取り分を取った後、目標にまだ必要な額をすべてポケットから充てます。
- **目標通貨での固定額**。
- **ポケットの割合（%）**：ポケットの評価額のうち、最大でその割合まで。
- **目標の割合（%）**：目標金額のうち、最大でその割合まで。

編集画面のプレビューには、その接続で今日時点でいくら充当されるかが表示されます。上限はあくまで最大値です。目標の順序、配分可能な貯蓄、他の接続によって充当額が減る場合があります。一覧の各資金源には、現在の充当額と、それ以上充当されない理由が表示されます。**接続を編集** で上限を変更し、**接続を解除** で接続を削除します。

**貯蓄予定。** この目標に届く貯蓄予定と、予測がそれぞれに割り当てる金額です。先に並ぶ目標で使い切られる貯蓄予定は、ここには表示されません。

**予測の読み方。** 「貯蓄予定により 2026年12月20日 に目標達成の見込み · 期限内」は、その日までの貯蓄予定の累計で、期限より前に不足額を賄えることを意味します。「貯蓄予定で … までに … 中 … を確保 · … 不足」は、賄えないことを意味します。貯蓄予定を追加するか、期限を変更するか、目標金額を下げてください。
