# プライバシーポリシー

<p class="meta">Android版Capital（パッケージ <code>dev.capital</code>） · 開発者：{{ site.developer }} · 2026年9月30日施行</p>

## 概要

- Capitalには、ユーザーアカウント、アナリティクス、広告、クラッシュレポートはなく、開発者が運営するサーバーもありません。開発者があなたのデータを受け取ることはありません。
- あなたの資産に関する記録は、あなたが選んだ端末上のフォルダにのみ保存されます。パスワードで暗号化することもできます。
- ネットワーク通信は、あなたの指示によりアプリが、「設定」で選択した価格データおよびブロックチェーンデータの事業者と、接続したブローカー口座のブローカーに送るリクエストだけです。これらのリクエストには、あなたが追跡している公開ウォレットアドレス、トークンのコントラクト、通貨コード、その事業者用に入力したAPIキー、ブローカー口座の場合はあなたが作成したアクセストークンと口座ID（またはクエリID）が含まれます。

## アプリが端末に保存するもの

**あなたが選んだフォルダ内。** ポケット、保有資産、ウォレットアドレス、目標、接続、貯蓄予定、キャッシュした価格、およびそれらのデータに属する設定。暗号化（設定 → セキュリティ）をオンにしない限り、ファイルはプレーンテキストです。暗号化をオンにすると、すべてのファイルは、パスワードからArgon2idで導出した鍵を使ってAES-256-GCMで暗号化されます。パスワードは復旧できません。

**アプリ専用ストレージ内**（他のアプリからはアクセスできません）：

| 項目 | 目的 |
|---|---|
| 選択したフォルダへのアクセス権 | 次回起動時にフォルダを開き直す |
| 入力したプロバイダのAPIキーとブローカーのアクセストークン | 発行元の事業者またはブローカーにのみ送信。Android Keystoreで保持する鍵で暗号化。スナップショット、エクスポート、OSのバックアップには含まれない |
| ロック設定 | パスワードなしで暗号化されたフォルダのロックを解除するため：データ鍵のコピーを、PINから導出しAndroid Keystoreに紐付けた鍵で暗号化したもの。PIN自体は保存されない |
| 言語とテーマの選択 | インターフェースの設定 |

このアプリではAndroidのバックアップと端末間転送が無効になっているため、これらがシステムによってGoogleや他の端末にコピーされることはありません。

## 端末の外に送信されるもの

Capitalが通信するのは、あなたが「設定」で選んだ事業者だけです。通信はHTTPSのみで、あなたが更新または取得元のテストを行ったときにだけ行われます。各リクエストは応答を受け取った後に破棄されます。アプリはフォルダに、返された残高と価格を保存し、リクエスト自体は保存しません。

| 送信されるデータ | 送信先 | 理由 |
|---|---|---|
| あなたが追加した公開ウォレットアドレス | そのチェーン用に選択したブロックチェーンデータ事業者 | アドレスの残高と保有トークンを読み取るため |
| トークンのコントラクトアドレスと資産ID | 選択した暗号資産価格の事業者 | 資産の価格を取得するため |
| 通貨コード | 選択した法定通貨レートの事業者 | 通貨間の換算のため |
| 事業者用に入力したAPIキー | その事業者のみ | その事業者でのあなた自身のアカウントを認証するため |
| ブローカー口座のアクセストークンまたはAPIキーと、口座ID（またはクエリID） | そのブローカーのみ（[ブローカー・FX口座]({{ page.base }}/accounts)を参照） | 口座の評価額の合計を読み取るため |

どのインターネット通信とも同じく、各事業者にはあなたのIPアドレスも伝わります。事業者は開発者から独立しており、それぞれの利用規約とプライバシーポリシーに従ってリクエストを処理します。これらはアプリの「設定 → 取得元／クレジット」からリンクされています：

| データ | 事業者 |
|---|---|
| ビットコイン | [Blockstream](https://blockstream.info), [mempool.space](https://mempool.space) |
| イーサリアムとERC-20トークン | [PublicNode](https://publicnode.com), [Alchemy](https://www.alchemy.com), [Blockscout](https://www.blockscout.com), [Ethplorer](https://ethplorer.io) |
| TONとジェットン | [TON Center](https://toncenter.com), [TonAPI](https://tonapi.io) |
| TRONとTRC-20トークン | [TronGrid](https://www.trongrid.io), [PublicNode](https://publicnode.com) |
| 暗号資産の価格 | [DefiLlama](https://defillama.com), [CoinGecko](https://www.coingecko.com), [CoinPaprika](https://coinpaprika.com) |
| 法定通貨のレート | [Frankfurter](https://frankfurter.dev), [欧州中央銀行](https://www.ecb.europa.eu) |
| ブローカー口座 | [Interactive Brokers](https://www.interactivebrokers.com), [OANDA](https://www.oanda.com), [Trading 212](https://www.trading212.com), [SnapTrade](https://snaptrade.com), [Alpaca](https://alpaca.markets), [Tradier](https://tradier.com), [tastytrade](https://tastytrade.com), [Public.com](https://public.com), [eToro](https://www.etoro.com), [Indexa Capital](https://indexacapital.com), [T-Invest](https://www.tbank.ru/invest/), [ALOR](https://www.alorbroker.ru), [Capital.com](https://capital.com), [Akahu](https://www.akahu.nz) |

これら以外にデータが送信されることはありません。データを販売したり、広告目的で共有したり、プロファイルの作成に使ったりすることはありません。公開ブロックチェーンへの問い合わせにより、あなたのIPアドレスの誰かがそのアドレスに関心を持っていることが事業者に伝わります。それが気になる場合はVPNを使用してください。

## アプリが決して行わないこと

- 秘密鍵やシードフレーズを求めたり、保存したり、送信したりすることはありません。トランザクションに署名したり送信したりすることもできません。
- お金を送金することはありません。目標への配分は画面に表示される計算結果であり、それ以上のものではありません。
- ブローカーに注文や指示を送ることは一切ありません。ブローカーへのアクセスは口座の評価額の読み取りにのみ使われます。[ブローカー・FX口座]({{ page.base }}/accounts)を参照してください。
- 開発者と通信することはありません。テレメトリ、アプリ内のアップデート確認、プッシュ通知はありません。

## 権限

| 権限 | 用途 |
|---|---|
| インターネット | 上記の事業者へのリクエスト |
| フォルダへのアクセス | あなたが選択したフォルダについて、Androidのフォルダ選択画面を通じてあなたが許可するもの。アプリは他のフォルダを読み取れない |
| 生体認証 | Android標準のプロンプトで指紋または顔によりロックを解除。アプリが受け取るのは成功か失敗かだけで、生体データを受け取ることはない |

## 同期とバックアップ

Capital自体は何も同期しません。フォルダを同期ツール（Syncthing、Nextcloud、Google Driveなど）で同期する場合、そのツールが作成するコピーにはそのツールのプライバシー規約が適用されます。暗号化がオンでない限り、ファイルはプレーンテキストです。暗号化をオンにする前に作成された暗号化なしのコピーは、それを持っている人なら誰でも読み取れる状態のままです。

「設定」の **バックアップをエクスポート** は、あなたが選んだ場所に1つのファイルを書き出します。このファイルには同じ記録が含まれ、その保護の強さは保存場所の安全性と同じです。

## データの削除

選択したフォルダ（および同期ツールが作成したコピー）を削除し、アプリをアンインストールしてください。アンインストールすると、プロバイダキーやロック設定を含むアプリ専用ストレージが削除されます。開発者は削除すべきデータを何も保持しておらず、あなたに代わって何かを削除することもできません。問い合わせ先の事業者は、それぞれの保存ルールに従ってリクエストのログを保持する場合があります。

## 寄付 {#donations}

アプリ（「概要」のハートボタン）とこのサイトには、任意のチップのための開発者のウォレットアドレスが表示されます。チップとは、あなたが自身のウォレットからそれらのアドレスのいずれかへ、ご利用のウォレットとネットワークの条件に従って行う送金です。Capitalはこれに一切関与しません。支払いを処理せず、あなたが送金したかどうかを知ることもできず、それについて何も記録せず、何も変更しません。機能が解放されたり変わったりすることはありません。チップの目的は開発者を支援することだけです。他のブロックチェーン取引と同様に、公開アドレスへ送金すると、そのネットワーク上であなたの送金元アドレスが公開されます。

## 子ども

Capitalは成人向けの個人資産管理ツールです。13歳未満の子どもを対象としておらず、子どもから故意にデータを収集することはありません。
