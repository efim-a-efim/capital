# Soutenir le développeur

Si vous souhaitez soutenir le développeur, utilisez l’un des moyens ci-dessous. Cela ne change rien au fonctionnement de l’application, mais aide le développeur.

{% include tips.html %}

Un don est un transfert depuis votre propre portefeuille crypto vers l’adresse du développeur. L’application et ce site n’y prennent aucune part et ne peuvent pas le voir ; rien n’est débloqué, enregistré ni modifié. Les mêmes adresses sont affichées dans l’application, sous le bouton en forme de cœur de la Synthèse. Voir [Dons]({{ page.base }}/privacy#donations) dans la Politique de confidentialité.
