# ব্রোকার ও ফরেক্স অ্যাকাউন্ট

Capital ক্রিপ্টো ওয়ালেটের মতোই ব্রোকারেজ বা ফরেক্স অ্যাকাউন্টের মোট মূল্য পড়তে পারে। আপনি অ্যাকাউন্টটি একটি তহবিলে **ব্রোকার অ্যাকাউন্ট** ধরনের সম্পদ হিসেবে যোগ করেন, আর প্রতিটি রিফ্রেশে অ্যাপ অ্যাকাউন্টের মূল মুদ্রায় তার নিট সম্পদ মূল্য (net asset value) আনে। অ্যাপ শুধু পড়ে: এটি ব্রোকারের রিপোর্টিং ইন্টারফেস ব্যবহার করে, এমন একটি টোকেন দিয়ে যা আপনি নিজে তৈরি করেন; এটি কখনও অর্ডার দেয় না, বদলায় না বা বাতিল করে না, এবং কখনও অর্থ সরায় না।

Capital শুধু এমন ইন্টারফেসের সঙ্গে যুক্ত হয়, যার ক্রেডেনশিয়াল দীর্ঘস্থায়ী: একটি টোকেন বা কী, যা আপনি একবার তৈরি করেন এবং বাতিল না করা পর্যন্ত, আপনার বেছে নেওয়া মেয়াদ পর্যন্ত, বা অন্তত কয়েক মাস বৈধ থাকে (T-Invest-এর টোকেন তিন মাস ব্যবহার না হলে অকেজো হয়, ALOR-এর টোকেন এক বছর পরে)। নিচের প্রতিটি ব্রোকার অ্যাপ যে ভাষাতেই থাকুক না কেন পাওয়া যায়। আজ যা সমর্থিত:

|---|---|---|

| [Trading 212](#trading-212) | Public API, Invest ও Stocks ISA অ্যাকাউন্ট | রিফ্রেশের সময়ের অ্যাকাউন্টের মোট মূল্য, অ্যাকাউন্টের প্রধান মুদ্রায় |

## শুরু করার আগে {#before-you-start}

- **ডিভাইস থেকে কী বাইরে যায়।** প্রতিটি রিফ্রেশে অ্যাপ HTTPS-এর মাধ্যমে আপনার অ্যাক্সেস টোকেন এবং অ্যাকাউন্ট বা কোয়েরি আইডি সেই ব্রোকারের কাছে পাঠায়। যেকোনো অনুরোধের মতোই ব্রোকার আপনার IP ঠিকানা দেখতে পায়।
- **ক্রেডেনশিয়াল কোথায় থাকে।** ব্রোকার ট্যাব → ক্রেডেনশিয়াল। এটি Android Keystore-এ রাখা একটি কী দিয়ে এনক্রিপ্ট করা, আপনার ডেটা ফোল্ডারে কখনও লেখা হয় না, এবং এক্সপোর্ট ও সিস্টেম ব্যাকআপ থেকে বাদ থাকে। প্রতিটি ব্রোকারের জন্য একসেট ক্রেডেনশিয়ালই সেই ব্রোকারের যোগ করা সব অ্যাকাউন্টের জন্য যথেষ্ট।
- **আপনার ফোল্ডারে কী সংরক্ষিত হয়।** অ্যাকাউন্ট আইডি, সর্বশেষ পড়া মূল্য এবং কখন পড়া হয়েছে। ব্রোকারের কাছ থেকে আর কিছুই নয়।
- **ব্রোকারের স্ক্রিন বদলাতে পারে।** নিচের ধাপগুলো 2026 সালের অক্টোবর পর্যন্ত ব্রোকারদের ওয়েবসাইটের সঙ্গে মেলে। ব্রোকাররা সময়ে সময়ে মেনুর নাম বদলায় ও সেটিং সরায়, তাই ধাপ অনুসরণ করার সময় কিছুটা আলাদা দেখাতে পারে। প্রতিটি অংশে দেওয়া ব্রোকারের নিজস্ব ডকুমেন্টেশনই প্রামাণিক উৎস: এখানকার কোনো ধাপ আর না মিললে ব্রোকারের পাতায় একই শব্দ খুঁজুন।

## Interactive Brokers {#interactive-brokers}

Capital **Flex Web Service** ব্যবহার করে, যা পূর্বনির্ধারিত রিপোর্ট আনার জন্য Interactive Brokers-এর ইন্টারফেস। এর টোকেন শুধু রিপোর্ট তৈরি ও ডাউনলোড করতে পারে; এটি দিয়ে লগইন, ট্রেড বা টাকা তোলা যায় না। Capital একটি Activity Flex Query-এর **Net Asset Value (NAV) Summary in Base** চায় এবং সর্বশেষ রিপোর্ট তারিখের মোট অঙ্ক নেয়, তাই মূল্যটি শেষ কার্যদিবসের ক্লোজিং মূল্য।

### 1. Flex Query তৈরি করুন

1. [Client Portal](https://www.interactivebrokers.com/portal)-এ লগইন করে **Performance & Reports → Flex Queries** খুলুন (কিছু অ্যাকাউন্টে মেনুর নাম *Reporting*)।
2. **Activity Flex Query**-এর নিচে **+** (Create) চাপুন। কোয়েরিটির একটি নাম দিন, যেমন `Capital`।
3. **Sections** তালিকায় ঠিক এই দুটি সেকশন ও ফিল্ড চালু করুন (সেকশনের সব ফিল্ড বেছে নিলেও চলে):
   - **Account Information**: *Account ID*, *Currency*।
   - **Net Asset Value (NAV) Summary in Base**: *Report Date*, *Total*।
4. **Delivery Configuration**-এ **Format** `XML` এবং **Period** `Last Business Day` করুন। বাকি অপশন ডিফল্টে রাখা যায়।
5. কোয়েরিটি সংরক্ষণ করুন, তারপর তার পাশের **i** (তথ্য) আইকন চেপে **Query ID** টুকে রাখুন, এটি একটি সংখ্যা।

কোয়েরিটি একটি অ্যাকাউন্টকে কভার করবে। আপনার লিংক করা অ্যাকাউন্ট বা অ্যাডভাইজর কাঠামো থাকলে প্রতিটি অ্যাকাউন্টের জন্য আলাদা কোয়েরি বানান এবং তৈরির সময় শুধু সেই অ্যাকাউন্টটি বেছে নিন।

### 2. Flex Web Service চালু করে টোকেন তৈরি করুন

1. একই **Flex Queries** পাতায় **Flex Web Service Configuration** খুলুন।
2. **Flex Web Service Status** চালু করে সংরক্ষণ করুন। একটি টোকেন তৈরি হবে।
3. টোকেন কতক্ষণ বৈধ থাকবে তা বাছতে **Generate New Token** চাপুন: 6 ঘণ্টা থেকে 1 বছর পর্যন্ত। ফোনের ঠিকানা বদলায়, তাই **Valid for IP address** ফাঁকা রাখুন। নতুন টোকেন তৈরি করলে আগেরটি অচল হয়ে যায়।
4. টোকেনটি কপি করুন।

### 3. Capital-এ সংযুক্ত করুন

1. **ব্রোকার → ক্রেডেনশিয়াল → অ্যাক্সেস টোকেন: Interactive Brokers**-এ টোকেনটি পেস্ট করে সংরক্ষণ করুন।
2. **ব্রোকার → +**: একটি নাম লিখুন, **ব্রোকার**-এ Interactive Brokers বেছে নিন, **Flex Query id** লিখে সংরক্ষণ করুন।
3. তহবিলটি খুলে **সম্পদ যোগ করুন** চাপুন, **ট্র্যাকিং**-এ **ব্রোকার অ্যাকাউন্ট** বেছে নিন, অ্যাকাউন্টটি বেছে সংরক্ষণ করুন।
4. **রিফ্রেশ করুন** চাপুন। প্রথমবার আধা মিনিট পর্যন্ত লাগে, কারণ রিপোর্টটি অনুরোধের পর তৈরি হয়।

টোকেনের মেয়াদ শেষ হলে রিফ্রেশে জানানো হয় *টোকেনের মেয়াদ শেষ; Client Portal-এ নতুন একটি তৈরি করুন*: নতুন টোকেন তৈরি করে ক্রেডেনশিয়ালের অধীনে পেস্ট করুন। Interactive Brokers একটি টোকেন থেকে সেকেন্ডে একটি এবং মিনিটে দশটি রিপোর্ট অনুরোধ অনুমোদন করে; একটি রিফ্রেশ কখনও তা ছাড়ায় না।

Interactive Brokers ডকুমেন্টেশন: [Flex Web Service](https://www.interactivebrokers.com/docs/web-api/flex-web-service/introduction) · [Enable and create the access token](https://www.interactivebrokers.com/docs/web-api/flex-web-service/client-portal-configuration/enable-and-create-access-token) · [Create a Flex Query](https://www.interactivebrokers.com/docs/web-api/flex-web-service/client-portal-configuration/create-a-flex-query) · [Activity Flex Query reference](https://www.ibkrguides.com/reportingreference/reportguide/activity%20flex%20query%20reference.htm) · [Net Asset Value (NAV) Summary in Base](https://www.ibkrguides.com/reportingreference/reportguide/net%20asset%20value%20%28nav%29%20summary%20in%20base.htm)

## OANDA {#oanda}

Capital OANDA v20 REST API-এর **অ্যাকাউন্ট সারসংক্ষেপ** (account summary) কল করে এবং অ্যাকাউন্টের NAV (ব্যালান্স ও অনাদায়ী লাভ বা ক্ষতি মিলিয়ে) অ্যাকাউন্টের মুদ্রায় সংরক্ষণ করে। শুধু লাইভ **fxTrade** অ্যাকাউন্ট সমর্থিত; প্র্যাকটিস অ্যাকাউন্ট সঞ্চয় নয়।

**OANDA-এর ব্যক্তিগত অ্যাক্সেস টোকেন শুধু-পড়ার নয়।** এটি আপনার লগইনের প্রতিটি সাব-অ্যাকাউন্টে ট্রেডিংসহ পূর্ণ API অ্যাক্সেস দেয়। Capital শুধু অ্যাকাউন্ট সারসংক্ষেপ কল করে, কিন্তু টোকেনটি যার হাতে পড়বে সে এটি দিয়ে ট্রেড করতে পারবে। এটিকে পাসওয়ার্ডের মতো গণ্য করুন: শুধু Capital-এ পেস্ট করুন, আর ফোন হারালে OANDA পোর্টালে এটি বাতিল করুন।

### 1. টোকেন তৈরি করুন

1. আপনার OANDA fxTrade অ্যাকাউন্ট ম্যানেজমেন্ট পোর্টালে লগইন করুন।
2. **My Services → Manage API Access** খুলুন (পুরোনো পোর্টালে: *My Account → My Services → Manage API Access*)।
3. API লাইসেন্স গ্রহণ করে **Generate** চাপুন। টোকেনটি কপি করুন; OANDA সেটি আর দেখায় না। হারিয়ে ফেললে সেখানে বাতিল করে নতুন একটি তৈরি করুন।

### 2. অ্যাকাউন্ট আইডি খুঁজুন

v20 অ্যাকাউন্ট আইডির রূপ `001-001-1234567-001`, হাইফেনসহ। একই পোর্টালে প্রতিটি সাব-অ্যাকাউন্টের পাশে এটি তালিকাভুক্ত থাকে, আর fxTrade প্ল্যাটফর্মে অ্যাকাউন্টের বিবরণে পাওয়া যায়।

1. **ব্রোকার → ক্রেডেনশিয়াল → অ্যাক্সেস টোকেন: OANDA**-এ টোকেনটি পেস্ট করে সংরক্ষণ করুন।

3. তহবিলটি খুলে **সম্পদ যোগ করুন** চাপুন, **ট্র্যাকিং**-এ **ব্রোকার অ্যাকাউন্ট** বেছে নিন, অ্যাকাউন্টটি বেছে সংরক্ষণ করুন।
4. **রিফ্রেশ করুন** চাপুন।

যে মার্জিন অ্যাকাউন্টের NAV ঋণাত্মক, সেটি সঞ্চয় হিসেবে গণনা না করে ত্রুটি হিসেবে জানানো হয়।

## Trading 212 {#trading-212}

Capital Trading 212 Public API-এর **অ্যাকাউন্ট সারসংক্ষেপ** (account summary) কল করে এবং অ্যাকাউন্টের প্রধান মুদ্রায় অ্যাকাউন্টের মোট মূল্য সংরক্ষণ করে। API **Invest** ও **Stocks ISA** অ্যাকাউন্ট কভার করে; একটি কী জোড়া একটি অ্যাকাউন্টের, আর Capital একটিই কী জোড়া রাখে, তাই এটি একটি Trading 212 অ্যাকাউন্ট পড়ে।

### 1. API কী তৈরি করুন

1. Trading 212 অ্যাপ বা ওয়েবসাইটে মেনু (**☰**) → **Settings** → **API (Beta)** খুলে ঝুঁকির সতর্কতা গ্রহণ করুন।
2. **Generate API key** চাপুন। একটি নাম দিন, শুধু **Account data** অনুমতি (পড়া) রাখুন, আর IP অ্যাক্সেস *Unrestricted* বেছে নিন (ফোনের ঠিকানা বদলায়)।
3. জমা দিন। দুটি মানই কপি করুন: **API Key** ও **API Secret Key**। সিক্রেট একবারই দেখানো হয়; হারিয়ে ফেললে কী মুছে নতুন জোড়া তৈরি করুন।

2. **ব্রোকার → +**: একটি নাম লিখুন, **ব্রোকার**-এ Trading 212 বেছে নিন, **Trading 212 অ্যাকাউন্ট নম্বর** (অ্যাপে দেখানো অ্যাকাউন্ট আইডি, শুধু অঙ্ক) লিখে সংরক্ষণ করুন।
3. তহবিলটি খুলে **সম্পদ যোগ করুন** চাপুন, **ট্র্যাকিং**-এ **ব্রোকার অ্যাকাউন্ট** বেছে নিন, অ্যাকাউন্টটি বেছে সংরক্ষণ করুন।
4. **রিফ্রেশ করুন** চাপুন। Trading 212 প্রতি 5 সেকেন্ডে একটি সারসংক্ষেপ অনুরোধ অনুমোদন করে।

## SnapTrade {#snaptrade}

কী পাঠানো হয়: আপনার ক্লায়েন্ট আইডি, আর স্বাক্ষর হিসেবে কনজিউমার কী নিজে কিছুই নয় (অনুরোধগুলো সেটি দিয়ে স্বাক্ষর করা হয়)। আপনার ব্রোকারের সঙ্গে সংযোগ ধরে রাখে SnapTrade, Capital নয়; সেই সংযোগে SnapTrade-এর শর্তাবলী ও গোপনীয়তা নীতি প্রযোজ্য।

2. **ব্রোকার → +**: একটি নাম লিখুন এবং **ব্রোকার**-এ SnapTrade বেছে নিন।
3. **SnapTrade-এর মাধ্যমে একটি ব্রোকারেজ সংযুক্ত করুন** চাপুন। ব্রাউজারে SnapTrade Connection Portal খুলবে; সেখানে আপনার ব্রোকারে লগইন করুন (লিংকটি 5 মিনিট বৈধ)। তারপর Capital-এ ফিরে আসুন।

eToro-র কী দীর্ঘস্থায়ী; আপনি সেগুলোতে মেয়াদ-শেষের তারিখ ও IP তালিকা দিতে পারেন, এবং সেগুলোকে শুধু-পড়ার করতে পারেন। আপনার eToro অ্যাকাউন্ট যাচাইকৃত হতে হবে।

1. eToro-তে **Settings → Trading → API Key Management** খুলুন এবং **Create New Key** চাপুন। **Real** এনভায়রনমেন্ট, **Read** অনুমতি, কোনো IP তালিকা নয়, এবং ইচ্ছে হলে একটি মেয়াদ-শেষের তারিখ বেছে নিন। SMS কোড দিয়ে নিশ্চিত করুন।
2. **Public API Key** ও **User Key** কপি করুন; ইউজার কী শুধু একবার দেখানো হয়।
3. Capital-এ সেগুলো **পাবলিক API কী: eToro** ও **ইউজার কী: eToro** হিসেবে পেস্ট করুন, তারপর [অ্যাকাউন্ট সংযুক্ত করা](#connect) অনুসরণ করুন। **অ্যাকাউন্ট আনুন** আপনার ট্রেডিং, ক্যাশ ও অন্যান্য eToro অ্যাকাউন্ট দেখায়।

eToro ডকুমেন্টেশন: [Authentication](https://api-portal.etoro.com/core/getting-started/authentication) · [Balances](https://api-portal.etoro.com/api-reference/balances/get-aggregated-balances) · [Getting started](https://builders.etoro.com/get-started)

## Indexa Capital {#indexa-capital}

## T-Invest {#t-invest}

T-Bank-এর T-Invest API এমন একটি টোকেন গ্রহণ করে যা আপনি বিনিয়োগ সেটিংসে ইস্যু করেন। টোকেন শেষ ব্যবহারের তিন মাস পরে অকেজো হয়ে যায় এবং ইস্যুর সাত দিনের মধ্যে ব্যবহার করতে হয়; সাপ্তাহিক রিফ্রেশ এটিকে সচল রাখে। একটি **শুধু-পড়ার** টোকেন বেছে নিন।

1. [T-Invest সেটিংস](https://www.tbank.ru/invest/settings/) খুলুন এবং এক্সচেঞ্জের জন্য **শুধু-পড়ার** অ্যাক্সেসসহ (সব অ্যাকাউন্ট বা একটি) একটি **T-Invest API টোকেন** ইস্যু করুন। ইস্যু করতে কোডের মাধ্যমে ট্রেড নিশ্চিতকরণ বন্ধ থাকতে হবে। টোকেনটি কপি করুন; এটি শুধু একবার দেখানো হয়।
2. Capital-এ সেটি **অ্যাক্সেস টোকেন: T-Invest** হিসেবে পেস্ট করুন, তারপর [অ্যাকাউন্ট সংযুক্ত করা](#connect) অনুসরণ করুন।

T-Bank এই API পরিবেশন করে Russian Trusted Root CA-এর অধীনে, যা Android-এ অন্তর্ভুক্ত নয়। Capital সেই সার্টিফিকেটে শুধু T-Invest API ঠিকানার (`invest-public-api.tbank.ru`) জন্য আস্থা রাখে, আর কোনো সংযোগের জন্য নয়।

T-Invest ডকুমেন্টেশন: [Tokens](https://developer.tbank.ru/invest/intro/intro/token) · [GetPortfolio](https://developer.tbank.ru/invest/api/operations-service-get-portfolio)

## ALOR {#alor}

ALOR এক বছর বৈধ একটি রিফ্রেশ টোকেন দেয়; প্রতিটি রিফ্রেশে Capital সেটি দিয়ে ৩০ মিনিটের একটি অ্যাক্সেস টোকেন নেয়। ALOR শুধু-পড়ার টোকেন দেয় না: টোকেন দিয়ে ট্রেড করা সম্ভব, Capital শুধু পড়ে।

1. [ALOR ডেভেলপার পোর্টালে](https://alor.dev) সাইন ইন করুন, আপনার ট্রেডিং অ্যাকাউন্ট যুক্ত করুন, **API Access Tokens** খুলুন এবং **Create Token** চাপুন। রিফ্রেশ টোকেনটি কপি করুন।
2. Capital-এ সেটি **রিফ্রেশ টোকেন: ALOR** হিসেবে পেস্ট করুন, তারপর [অ্যাকাউন্ট সংযুক্ত করা](#connect) অনুসরণ করুন। **অ্যাকাউন্ট আনুন** অ্যাকাউন্টের পোর্টফোলিওগুলো দেখায় (শেয়ার বাজার D…, মুদ্রা বাজার G…, ডেরিভেটিভ 7500…); প্রতিটি পোর্টফোলিওর জন্য একটি করে যোগ করুন।

ALOR ডকুমেন্টেশন: [Refresh token](https://alor.dev/docs/en/api/access/authorization/refresh-token) · [Access token](https://alor.dev/docs/en/api/access/authorization/access-token)

## Capital.com {#capital-com}

Capital.com-এর কী ডিফল্টভাবে এক বছর, অথবা আপনার বেছে নেওয়া তারিখ পর্যন্ত বৈধ। এগুলোতে ট্রেডিংয়ের অধিকার থাকে (Capital.com-এ শুধু-পড়ার কী নেই); Capital শুধু পড়ে। কী-এর নিজস্ব একটি পাসওয়ার্ড থাকে, যা আপনার অ্যাকাউন্টের পাসওয়ার্ড নয়।

1. টু-ফ্যাক্টর প্রমাণীকরণ চালু করুন, তারপর **Settings → API integrations** খুলুন এবং **Generate API key** চাপুন। একটি লেবেল ও একটি **কাস্টম পাসওয়ার্ড** দিন, মেয়াদ রাখুন বা ঠিক করুন, এবং 2FA কোড দিয়ে নিশ্চিত করুন। কী-টি কপি করুন; এটি শুধু একবার দেখানো হয়।
2. Capital-এ **API কী: Capital.com** পেস্ট করুন, আপনার লগইন ই-মেইল **লগইন ই-মেইল: Capital.com** হিসেবে এবং কাস্টম পাসওয়ার্ডটি **API কী পাসওয়ার্ড: Capital.com** হিসেবে দিন, তারপর [অ্যাকাউন্ট সংযুক্ত করা](#connect) অনুসরণ করুন। শুধু লাইভ অ্যাকাউন্ট পড়া হয়।

Capital.com ডকুমেন্টেশন: [Public API](https://open-api.capital.com/)

## অন্যান্য ব্রোকার {#other-brokers}

Capital শুধু এমন ইন্টারফেসের সঙ্গে যুক্ত হয়, যা ফোন থেকে HTTPS-এর মাধ্যমে চলে, যার টোকেন আপনি নিজে তৈরি করতে পারেন এবং যা দিয়ে ট্রেড না করে শুধু পড়া যায়। তাই আপাতত এগুলো বাদ:

- **MetaTrader 4 ও 5** অ্যাকাউন্ট। ইনভেস্টর পাসওয়ার্ড শুধু-পড়ার অ্যাক্সেস দেয়, কিন্তু কেবল MetaTrader টার্মিনালের ভেতরে; ব্রোকাররা এর জন্য কোনো HTTPS ইন্টারফেস দেয় না।
- যেসব ব্রোকারের API-র জন্য কম্পিউটারে একটি প্রোগ্রাম চালু রাখতে হয় (যেমন Interactive Brokers Client Portal Web API গেটওয়ে; Capital এর বদলে Flex Web Service ব্যবহার করে) বা OAuth অ্যাপ্লিকেশন নিবন্ধন লাগে।
- যেসব ব্রোকারের API শুধু OAuth-এর মাধ্যমে স্বল্পস্থায়ী টোকেন দেয়, যেমন Saxo Bank (অ্যাক্সেস টোকেন 20 মিনিট টেকে; ডেভেলপার পোর্টালের 24-hour token শুধু সিমুলেশন এনভায়রনমেন্টে চলে)।
- যেসব ব্যাংক ও ব্রোকারের কোনো পাবলিক API নেই।

এই ব্রোকারদের অনেকে [SnapTrade](#snaptrade)-এর আওতায় পড়ে। নইলে ব্যালান্সটি **ম্যানুয়াল** সম্পদ হিসেবে লিখুন এবং স্টেটমেন্ট দেখলে সংখ্যাটি হালনাগাদ করুন। আপনার ব্রোকার অ্যাকাউন্টের মূল্য পড়ার জন্য টোকেনভিত্তিক কোনো সহজ HTTPS এন্ডপয়েন্ট দিলে তার ডকুমেন্টেশনের লিংকসহ [একটি ইস্যু খুলুন]({{ site.repo }}/issues)। Capital-এ প্রতিটি ব্রোকার একটি ছোট প্লাগইন; ডেভেলপাররা [প্লাগইন গাইড]({{ site.repo }}/blob/main/BROKER-PLUGINS.md) অনুসরণ করে নতুন একটি যোগ করতে পারেন।
