# بروکرز

**یہ کیا ہے۔** بروکریج اور فاریکس اکاؤنٹس سے آپ کے صرف پڑھنے والے کنکشن۔ بروکر اکاؤنٹ بروکر، اکاؤنٹ یا کوئری id اور بروکر کی سند پر مشتمل ہوتا ہے؛ ریفریش پر ایپ اکاؤنٹ کی کل مالیت اس کی بنیادی کرنسی میں پڑھتی ہے۔ اکاؤنٹس اسی اسکرین پر رہتے ہیں، گلک کے اندر نہیں: گلک صرف ان میں سے کسی سے منسلک ہوتا ہے، اور آپ کی بچت کا شمار گلک ہی میں ہوتا ہے۔

**ہر قطار کیا دکھاتی ہے۔** اکاؤنٹ کا نام، بروکر اور id، اکاؤنٹ کی کرنسی اور آپ کی ڈیفالٹ کرنسی میں آخری پڑھی گئی مالیت، وہ وقت جب وہ مشاہدہ ہوئی اور جب حاصل کی گئی، اور وہ گلک جس سے وہ منسلک ہے: **… سے منسلک** اس گلک کو کھولتا ہے، *کسی گلک سے منسلک نہیں* کا مطلب ہے کہ ابھی کوئی اسے شمار نہیں کر رہا۔ **ترمیم کریں** نام، بروکر یا id بدلتا ہے؛ **حذف کریں** اکاؤنٹ کو ہٹا دیتا ہے اور، اگر وہ منسلک تھا، تو اسے جوڑنے والے کھاتے کو بھی۔

**اکاؤنٹ شامل کرنا۔** **+** دبائیں، نام درج کریں، بروکر منتخب کریں اور وہ id درج کریں جو وہ بروکر استعمال کرتا ہے: Interactive Brokers کے لیے Flex Query id، OANDA کے لیے اکاؤنٹ id، Trading 212 کے لیے اکاؤنٹ نمبر۔ SnapTrade کے لیے **SnapTrade کے ذریعے بروکریج جوڑیں** دبائیں، واپس آئیں، **اکاؤنٹس حاصل کریں** دبائیں اور ایک منتخب کریں۔ محفوظ کریں۔ کرنسی اور مالیت اگلے ریفریش کے بعد ظاہر ہوتی ہیں۔

**اس سے کم بیلنس نظر انداز کریں۔** اسے منتخب کریں اور اپنی ڈیفالٹ کرنسی میں ایک رقم درج کریں (ڈیفالٹ 1) تاکہ معمولی رقمیں آپ کی بچت سے باہر رہیں: جب اکاؤنٹ کی مالیت، محفوظ شدہ ریٹس کے مطابق تبدیل کرنے کے بعد، اس رقم سے کم ہو تو منسلک کھاتہ 0 شمار ہوتا ہے اور قطار پر *0 شمار: … سے کم* لکھا ہوتا ہے۔ اصل مالیت اس اسکرین پر نظر آتی رہتی ہے۔ اکاؤنٹ کی کرنسی کا ریٹ نہ ہو تو کچھ بھی نظر انداز نہیں ہوتا۔

**اسے گلک سے منسلک کرنا۔** گلک کھولیں، **کھاتہ شامل کریں** دبائیں، **ٹریکنگ** کو **بروکر اکاؤنٹ** پر رکھیں اور اکاؤنٹ منتخب کریں؛ اکاؤنٹ کا نام استعمال کرنے کے لیے نام خالی چھوڑیں۔ ایک اکاؤنٹ ایک وقت میں ایک ہی گلک میں ہو سکتا ہے۔ کھاتے پر **ترمیم / منتقلی** اسے دوسرے گلک میں منتقل کرتا ہے؛ کھاتہ حذف کرنے سے اکاؤنٹ حذف کیے بغیر منسلکی ختم ہو جاتی ہے۔

**اسناد۔** ہر معاون بروکر (Interactive Brokers، OANDA، Trading 212، SnapTrade) کا ٹوکن یا کلید؛ ہر بروکر کا ایک سیٹ اس بروکر کے ہر اکاؤنٹ پر لاگو ہوتا ہے۔ یہ Android Keystore میں رکھی گئی کلید سے انکرپٹ ہوتی ہیں، ڈیٹا فولڈر میں کبھی نہیں لکھی جاتیں، ایکسپورٹس اور سسٹم بیک اپ میں شامل نہیں ہوتیں، اور صرف اسی بروکر کو بھیجی جاتی ہیں جس نے انہیں جاری کیا۔ **بروکر اکاؤنٹس کی سیٹ اپ گائیڈ** [بروکر اور فاریکس اکاؤنٹس]({{ page.base }}/accounts) کھولتی ہے، جس میں ہر بروکر کے مراحل درج ہیں۔

**ریفریش۔** اس اسکرین پر ریفریش آئیکن ہر اکاؤنٹ کو پڑھتا ہے؛ گلک پر ریفریش صرف اسی گلک سے منسلک اکاؤنٹس کو پڑھتا ہے۔ جو اکاؤنٹ پڑھا نہ جا سکے وہ اپنی آخری مالیت برقرار رکھتا ہے اور اپنی قطار کے نیچے بروکر کا پیغام دکھاتا ہے۔ ایپ صرف پڑھتی ہے: وہ کبھی کوئی آرڈر نہیں دیتی اور نہ رقم منتقل کرتی ہے۔
