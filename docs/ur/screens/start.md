# آغاز کی اسکرین

**یہ کیا ہے۔** انسٹالیشن کے بعد پہلی اسکرین، اور وہ اسکرین جو آپ تب دیکھتے ہیں جب ایپ کے پاس کام کرنے کے لیے کوئی فولڈر نہ ہو۔ ابھی کچھ بھی محفوظ نہیں ہوا۔

**یہ کیسے کام کرتی ہے۔** Capital ہر ریکارڈ آپ کی ڈیوائس کے ایک ہی فولڈر میں رکھتی ہے اور کہیں اور نہیں۔ **فولڈر منتخب کریں یا دوبارہ کھولیں** دبائیں اور اینڈرائیڈ کے فولڈر پکر میں ایک مخصوص فولڈر چنیں، مثلاً `Documents/Capital`۔ جس فولڈر میں پہلے سے Capital کی فائلیں ہوں وہ سیدھا کھل جاتا ہے، اس لیے یہی بٹن دوبارہ انسٹال کرنے کے بعد، یا کسی دوسری ڈیوائس پر جسے آپ کے سنک ٹول کے ذریعے فولڈر ملتا ہے، آپ کا ڈیٹا دوبارہ جوڑ دیتا ہے۔

**انتخاب سے پہلے:**

- وارننگ باکس بتاتا ہے کہ ڈیوائس سے باہر کیا جاتا ہے: عوامی والیٹ ایڈریس، ٹوکن کنٹریکٹ اور آپ کا IP ایڈریس ان ڈیٹا آپریٹرز کو جاتے ہیں جنہیں آپ بعد میں سیٹنگز میں چنتے ہیں۔ ایپ میں کہیں بھی نجی کلیدیں یا سیڈ فریز کبھی درج نہ کریں۔
- ڈیفالٹ کرنسی EUR ہے۔ فولڈر کھلنے کے بعد اسے سیٹنگز میں بدلیں۔

**اوپر کے بٹن۔** **?** یہ دستاویزات ایپ کی زبان میں کھولتا ہے۔ ریفریش اور سیٹنگز فولڈر کھلنے کے بعد نظر آتے ہیں۔
