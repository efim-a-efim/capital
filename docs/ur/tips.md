# ڈویلپر کو ٹپ دیں

اگر آپ ڈویلپر کو ٹپ دینا چاہتے ہیں تو نیچے دیے گئے طریقوں میں سے کوئی ایک استعمال کریں۔ اس سے ایپ کی فعالیت میں کوئی تبدیلی نہیں آئے گی، لیکن ڈویلپر کی مدد ہو گی۔

{% include tips.html %}

ٹپ آپ کے اپنے والیٹ سے ڈویلپر کے ایڈریس پر کی گئی منتقلی ہے۔ ایپ اور یہ سائٹ اس میں کوئی حصہ نہیں لیتیں اور اسے دیکھ نہیں سکتیں؛ نہ کچھ ان لاک ہوتا ہے، نہ ریکارڈ ہوتا ہے، نہ کچھ بدلتا ہے۔ یہی ایڈریس ایپ میں جائزہ اسکرین پر دل والے بٹن کے تحت دکھائے جاتے ہیں۔ رازداری کی پالیسی میں [عطیات]({{ page.base }}/privacy#donations) دیکھیں۔
