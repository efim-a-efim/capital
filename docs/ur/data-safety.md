# ڈیٹا کی حفاظت کا اعلامیہ

<p class="meta">Google Play Console کے فارم (Policy and programs → App content → Data safety — پالیسی اور پروگرامز ← ایپ کا مواد ← ڈیٹا کی حفاظت) کے جوابات، ہر جواب کی وجہ کے ساتھ۔ ورژن 2.2.1 کے مطابق 30 ستمبر 2026 کو جانچے گئے۔ انہی حقائق کا صارف کے لیے بیان <a href="{{ page.base }}/privacy">رازداری کی پالیسی</a> ہے۔</p>

## ایپ ڈیٹا کو کیسے سنبھالتی ہے

Capital کا کوئی بیک اینڈ نہیں۔ صارف جو کچھ درج کرتا ہے وہ ڈیوائس کے ایک فولڈر میں رہتا ہے۔ ڈیوائس سے باہر جانے والا واحد ڈیٹا وہ ہے جو ایپ صارف کے کہنے پر ان تھرڈ پارٹی ڈیٹا آپریٹرز کو بھیجتی ہے جنہیں صارف سیٹنگز میں منتخب کرتا ہے: عوامی والیٹ ایڈریس، ٹوکن کنٹریکٹ ID، کرنسی کوڈ اور وہ API کلید جو صارف نے اس آپریٹر کے لیے درج کی ہو۔ آپریٹرز درخواست کا جواب دیتے ہیں؛ ایپ واپس آنے والے بیلنس اور قیمتیں مقامی طور پر محفوظ کرتی ہے اور درخواست کی کوئی کاپی نہیں رکھتی۔ ایپ میں کوئی SDK خود سے کسی سرور کو ڈیٹا نہیں بھیجتا: ڈیپنڈنسیز صرف AndroidX، Kotlin، OkHttp اور Bouncy Castle ہیں۔

Google Play ڈیٹا کو *collected* (جمع شدہ) مانتا ہے جب وہ ڈیوائس سے باہر بھیجا جائے، چاہے ڈویلپر کا کوئی سرور شامل نہ ہو اور پراسیسنگ عارضی ہو، اس لیے اعلامیہ "کچھ جمع نہیں کیا جاتا" نہیں ہے۔ یہ ایک واحد، عارضی اور اختیاری ڈیٹا ٹائپ ہے۔

## فارم کے جوابات

### جائزہ

| سوال | جواب |
|---|---|
| Does your app collect or share any of the required user data types? (کیا آپ کی ایپ مطلوبہ اقسام میں سے کوئی یوزر ڈیٹا جمع یا شیئر کرتی ہے؟) | **Yes** (ہاں) |
| Is all of the user data collected by your app encrypted in transit? (کیا آپ کی ایپ کا جمع کردہ تمام یوزر ڈیٹا منتقلی کے دوران انکرپٹڈ ہوتا ہے؟) | **Yes** (ہاں) — صرف HTTPS؛ مینی فیسٹ میں غیر انکرپٹڈ ٹریفک بند ہے |
| Do you provide a way for users to request that their data is deleted? (کیا آپ صارفین کو اپنا ڈیٹا حذف کرنے کی درخواست کا طریقہ فراہم کرتے ہیں؟) | **Yes** (ہاں) — درخواست مکمل ہونے کے بعد کچھ بھی محفوظ نہیں رہتا، جو بیج کے لیے "جمع کرنے کے 90 دن کے اندر حذف" کی شرط پوری کرتا ہے۔ صارفین ڈیوائس پر موجود ڈیٹا فولڈر حذف کر کے اور ایپ ان انسٹال کر کے حذف کرتے ہیں؛ رازداری کی پالیسی دیکھیں۔ |

### ڈیٹا کی اقسام

بالکل ایک قسم منتخب کریں۔

| Category (زمرہ) | Data type (ڈیٹا کی قسم) | Collected (جمع شدہ) | Shared (شیئر شدہ) | Ephemeral (عارضی) | Required or optional (لازمی یا اختیاری) | Purposes (مقاصد) |
|---|---|---|---|---|---|---|
| Financial info (مالی معلومات) | Other financial info (دیگر مالی معلومات) | Yes (ہاں) | No (نہیں) | **Yes** (ہاں) | **Optional** (اختیاری) | App functionality (ایپ کی فعالیت) |

یہ قسم کن چیزوں کا احاطہ کرتی ہے: صارف کے ٹریک کردہ عوامی بلاک چین ایڈریس، ان پر ملنے والے ٹوکن کنٹریکٹ، اور صارف کے کھاتوں کے کرنسی کوڈ۔ یہ صارف کے منتخب کردہ ڈیٹا آپریٹر کو بھیجے جاتے ہیں تاکہ بیلنس اور قیمتیں حاصل کی جا سکیں، درخواست کے دوران میموری میں رکھے جاتے ہیں، اور پھر ختم کر دیے جاتے ہیں۔

**Shared نہ ہونے** کی وجہ: منتقلی براہ راست ڈیوائس سے صارف کے چنے ہوئے آپریٹر تک ہوتی ہے، صارف کے شروع کیے گئے ریفریش پر، اور اس کے بعد جب ایپ سیٹنگز میں صارف کو بتا چکی ہو کہ کس آپریٹر سے سوال کیا جائے گا اور یہ کہ درخواست اس آپریٹر پر ایڈریس اور IP ظاہر کرتی ہے۔ یہ "user-initiated action where the user reasonably expects the data to be shared" (صارف کا شروع کیا گیا ایسا عمل جس میں صارف معقول طور پر ڈیٹا شیئر ہونے کی توقع رکھتا ہے) والی استثنا ہے۔ ڈویلپر کو کچھ موصول نہیں ہوتا اور اس کا کوئی سروس پرووائیڈر نہیں۔

**Optional ہونے** کی وجہ: ایپ صرف دستی کھاتوں کے ساتھ پوری طرح قابلِ استعمال ہے۔ ایڈریس اور API کلیدیں صارف اپنی مرضی سے درج کرتا ہے۔

صارف کی درج کردہ API کلیدیں صرف اسی آپریٹر کو بھیجی جاتی ہیں جس نے انہیں جاری کیا۔ یہ اس آپریٹر کی اپنی سروس کے لیے صارف کی اسناد ہیں اور انہیں الگ یوزر ڈیٹا ٹائپ کے طور پر ظاہر نہیں کیا جاتا؛ اگر جائزہ لینے والا پوچھے تو انہیں اوپر کی طرح بیان کریں۔

### وہ اقسام جو جمع **نہیں** کی جاتیں

باقی ہر زمرہ "No" (نہیں) ہے: کوئی مقام نہیں، کوئی ذاتی معلومات نہیں، کوئی رابطے نہیں، کوئی پیغامات نہیں، کوئی تصاویر یا میڈیا نہیں، کوئی فائلیں اور دستاویزات نہیں، کوئی ایپ سرگرمی نہیں، کوئی ویب براؤزنگ نہیں، کوئی ایپ معلومات اور کارکردگی نہیں (کوئی کریش لاگز نہیں، کوئی تشخیصی ڈیٹا نہیں)، کوئی ڈیوائس یا دیگر شناخت کنندگان نہیں۔ IP ایڈریس کسی بھی HTTPS درخواست کے حصے کے طور پر آپریٹرز تک پہنچتے ہیں اور ایپ انہیں کسی مقصد کے لیے استعمال نہیں کرتی۔

صارف کا مالی ریکارڈ (کھاتے، اہداف، منصوبے) صرف ڈیوائس پر پراسیس ہوتا ہے اور اس فارم کے دائرے سے باہر ہے۔

## ایپ میں تبدیلی پر کیا اپ ڈیٹ کرنا ہے

جب کسی ریلیز میں اینالیٹکس، کریش رپورٹنگ، اکاؤنٹس، ڈویلپر کا چلایا ہوا سرور، نیٹ ورک تک رسائی والا نیا SDK، یا ڈیوائس پر کسی دوسری ایپ کے ساتھ شیئرنگ شامل ہو تو اس صفحے کی دوبارہ جانچ کریں۔ ان میں سے کوئی بھی تبدیلی فارم کو بدل دیتی ہے۔
