# Layar awal

**Apa ini.** Layar pertama setelah pemasangan, dan layar yang Anda lihat setiap kali aplikasi tidak punya folder untuk digunakan. Belum ada yang disimpan.

**Cara kerjanya.** Capital menyimpan semua data di satu folder di perangkat Anda dan tidak pernah di tempat lain. Tekan **Pilih atau buka kembali folder** lalu pilih folder khusus di pemilih folder Android, misalnya `Documents/Capital`. Folder yang sudah berisi file Capital langsung terbuka, sehingga tombol yang sama menghubungkan kembali data Anda setelah pemasangan ulang atau di perangkat kedua yang menerima folder itu melalui alat sinkronisasi Anda.

**Sebelum memilih:**

- Kotak peringatan menjelaskan apa yang keluar dari perangkat: alamat dompet publik, kontrak token, dan alamat IP Anda dikirim ke operator data yang nanti Anda pilih di Pengaturan. Jangan pernah memasukkan kunci privat atau seed phrase di bagian mana pun dari aplikasi.
- Mata uang default adalah EUR. Ubah di Pengaturan setelah folder terbuka.

**Tombol di bagian atas.** **?** membuka dokumentasi ini dalam bahasa aplikasi. Tombol perbarui dan Pengaturan muncul setelah folder terbuka.
