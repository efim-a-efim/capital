# Beri tip untuk developer

Jika Anda ingin memberi tip kepada developer, gunakan salah satu cara di bawah ini. Ini tidak akan mengubah apa pun pada fungsi aplikasi, tetapi akan membantu developer.

{% include tips.html %}

Tip adalah transfer dari dompet Anda sendiri ke alamat developer. Aplikasi dan situs ini tidak terlibat di dalamnya dan tidak dapat melihatnya; tidak ada yang dibuka, dicatat, atau diubah. Alamat yang sama ditampilkan di aplikasi melalui tombol hati di Ringkasan. Lihat [Donasi]({{ page.base }}/privacy#donations) di Kebijakan Privasi.
