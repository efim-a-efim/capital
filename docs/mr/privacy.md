# गोपनीयता धोरण

<p class="meta">Android साठी Capital (पॅकेज <code>dev.capital</code>) · डेव्हलपर: {{ site.developer }} · प्रभावी दिनांक: 30 सप्टेंबर 2026</p>

## सारांश

- Capital मध्ये वापरकर्ता खाती नाहीत, अॅनालिटिक्स नाही, जाहिराती नाहीत, क्रॅश रिपोर्टिंग नाही आणि डेव्हलपरचे कोणतेही सर्व्हर नाहीत. डेव्हलपरला तुमचा डेटा कधीही मिळत नाही.
- तुमच्या आर्थिक नोंदी फक्त तुमच्या डिव्हाइसवर, तुम्ही निवडलेल्या फोल्डरमध्ये साठवल्या जातात. तुम्ही त्या पासवर्डने एन्क्रिप्ट करू शकता.
- नेटवर्कवरून जाणारा एकमेव डेटा म्हणजे तुम्ही सांगितल्यावर, सेटिंग्जमध्ये तुम्ही निवडलेल्या भाव आणि ब्लॉकचेन डेटा प्रदात्यांना अॅप पाठवत असलेल्या विनंत्या. या विनंत्यांमध्ये तुम्ही ट्रॅक करत असलेले सार्वजनिक वॉलेट पत्ते, टोकन कॉन्ट्रॅक्ट आणि चलन कोड असतात, तसेच त्या प्रदात्यासाठी तुम्ही टाकलेली API की (असल्यास).

## अॅप तुमच्या डिव्हाइसवर काय साठवते

**तुम्ही निवडलेल्या फोल्डरमध्ये.** कप्पे, होल्डिंग, वॉलेट पत्ते, उद्दिष्टे, कनेक्शन, नियोजित बचत, कॅश केलेले भाव आणि त्या डेटाशी संबंधित सेटिंग्ज. एन्क्रिप्शन चालू केल्याशिवाय (सेटिंग्ज → सुरक्षा) फाइल्स साध्या मजकुरात असतात. एन्क्रिप्शन चालू असताना प्रत्येक फाइल AES-256-GCM ने एन्क्रिप्ट केली जाते; त्याची की तुमच्या पासवर्डमधून Argon2id ने तयार केली जाते. पासवर्ड पुनर्प्राप्ती उपलब्ध नाही.

**अॅपच्या खाजगी स्टोरेजमध्ये** (इतर अॅप्सना उपलब्ध नाही):

| घटक | उद्देश |
|---|---|
| निवडलेल्या फोल्डरची परवानगी | पुढच्या लाँचला फोल्डर पुन्हा उघडणे |
| तुम्ही टाकलेल्या प्रदाता API की | फक्त त्या की देणाऱ्या प्रदात्यालाच पाठवल्या जातात; Android Keystore मधील कीने एन्क्रिप्ट केलेल्या; स्नॅपशॉट, एक्सपोर्ट आणि OS बॅकअपमधून वगळलेल्या |
| लॉक सेटिंग्ज | पासवर्डशिवाय एन्क्रिप्टेड फोल्डर अनलॉक करणे: डेटा कीची प्रत, तुमच्या PIN मधून तयार केलेल्या आणि Android Keystore शी बांधलेल्या कीने एन्क्रिप्ट केलेली. PIN स्वतः साठवला जात नाही |
| भाषा आणि थीमची निवड | इंटरफेस प्राधान्ये |

या अॅपसाठी Android बॅकअप आणि डिव्हाइस-टू-डिव्हाइस ट्रान्सफर बंद आहेत, त्यामुळे यापैकी काहीही सिस्टमद्वारे Google कडे किंवा दुसऱ्या डिव्हाइसवर कॉपी होत नाही.

## तुमच्या डिव्हाइसबाहेर काय जाते

Capital फक्त सेटिंग्जमध्ये तुम्ही निवडलेल्या प्रदात्यांशी, फक्त HTTPS वरून, आणि फक्त तुम्ही रिफ्रेश करता किंवा स्रोत तपासता तेव्हाच संपर्क साधते. प्रत्येक विनंतीला उत्तर मिळते आणि ती टाकून दिली जाते; अॅप मिळालेल्या शिलकी आणि भाव तुमच्या फोल्डरमध्ये ठेवते, विनंती नाही.

| पाठवलेला डेटा | कोणाला | का |
|---|---|---|
| तुम्ही जोडलेले सार्वजनिक वॉलेट पत्ते | त्या चेनसाठी निवडलेला ब्लॉकचेन डेटा प्रदाता | पत्त्यावरील शिल्लक आणि टोकन होल्डिंग वाचणे |
| टोकन कॉन्ट्रॅक्ट पत्ते आणि मालमत्ता ID | तुम्ही निवडलेला क्रिप्टो भाव प्रदाता | मालमत्तांचे भाव मिळवणे |
| चलन कोड | तुम्ही निवडलेला फिएट दर प्रदाता | चलनांमध्ये रूपांतर करणे |
| एखाद्या प्रदात्यासाठी तुम्ही टाकलेली API की | फक्त तोच प्रदाता | त्यांच्याकडील तुमच्या स्वतःच्या खात्याचे प्रमाणीकरण |

कोणत्याही इंटरनेट विनंतीप्रमाणे, प्रत्येक प्रदात्याला तुमचा IP पत्ताही दिसतो. प्रदाते डेव्हलपरपासून स्वतंत्र आहेत आणि विनंतीवर त्यांच्या स्वतःच्या अटी व गोपनीयता धोरणांनुसार प्रक्रिया करतात; त्यांच्या लिंक अॅपमधील सेटिंग्ज → स्रोत / श्रेय येथे आहेत:

| डेटा | प्रदाते |
|---|---|
| Bitcoin | [Blockstream](https://blockstream.info), [mempool.space](https://mempool.space) |
| Ethereum आणि ERC-20 टोकन | [PublicNode](https://publicnode.com), [Alchemy](https://www.alchemy.com), [Blockscout](https://www.blockscout.com), [Ethplorer](https://ethplorer.io) |
| TON आणि जेटन | [TON Center](https://toncenter.com), [TonAPI](https://tonapi.io) |
| TRON आणि TRC-20 टोकन | [TronGrid](https://www.trongrid.io), [PublicNode](https://publicnode.com) |
| क्रिप्टो भाव | [DefiLlama](https://defillama.com), [CoinGecko](https://www.coingecko.com), [CoinPaprika](https://coinpaprika.com) |
| फिएट दर | [Frankfurter](https://frankfurter.dev), [युरोपियन सेंट्रल बँक](https://www.ecb.europa.eu) |

इतर कुठेही काहीही पाठवले जात नाही. कोणताही डेटा विकला जात नाही, जाहिरातींसाठी शेअर केला जात नाही किंवा प्रोफाइल तयार करण्यासाठी वापरला जात नाही. सार्वजनिक ब्लॉकचेन क्वेरींमुळे हे उघड होते की तुम्ही ट्रॅक करत असलेल्या पत्त्यात तुमच्या IP पत्त्यावरील कोणालातरी रस आहे; हे तुमच्यासाठी महत्त्वाचे असल्यास VPN वापरा.

## अॅप कधीही काय करत नाही

- ते खाजगी की किंवा सीड फ्रेज कधीही मागत नाही, साठवत नाही किंवा पाठवत नाही. ते व्यवहारांवर सही करू शकत नाही किंवा व्यवहार पाठवू शकत नाही.
- ते कधीही पैसे ट्रान्सफर करत नाही. उद्दिष्टांचे वाटप हे फक्त तुम्हाला दाखवलेले हिशेब आहेत, त्याहून अधिक काही नाही.
- ते डेव्हलपरशी कधीही संपर्क साधत नाही. टेलिमेट्री नाही, अॅपमध्ये अपडेट तपासणी नाही, पुश नोटिफिकेशन नाहीत.

## सिंक आणि बॅकअप

Capital स्वतः काहीही सिंक करत नाही. तुम्ही फोल्डर एखाद्या सिंक साधनाखाली (Syncthing, Nextcloud, Google Drive, …) ठेवल्यास, त्या साधनाने बनवलेल्या प्रतींना त्या साधनाच्या गोपनीयता अटी लागू होतात. एन्क्रिप्शन चालू नसल्यास फाइल्स साध्या मजकुरात असतात; एन्क्रिप्शन चालू करण्यापूर्वी बनलेल्या प्लेनटेक्स्ट प्रती ज्याच्याकडे असतील त्याला वाचता येतात.

सेटिंग्जमधील **बॅकअप एक्सपोर्ट करा** तुम्ही निवडलेल्या ठिकाणी एक फाइल लिहिते. त्यात त्याच नोंदी असतात आणि ती फक्त त्या ठिकाणाइतकीच सुरक्षित असते.

## तुमचा डेटा हटवणे

तुम्ही निवडलेले फोल्डर (आणि तुमच्या सिंक साधनाने बनवलेल्या सर्व प्रती) हटवा आणि अॅप अनइंस्टॉल करा. अनइंस्टॉल केल्याने अॅपचे खाजगी स्टोरेज, प्रदाता की आणि लॉक सेटिंग्जसह, काढून टाकले जाते. डेव्हलपरकडे हटवण्यासारखे काहीही नाही आणि तो तुमच्या वतीने काहीही हटवू शकत नाही. तुम्ही क्वेरी केलेले प्रदाते त्यांच्या स्वतःच्या नियमांनुसार विनंतींचे लॉग ठेवू शकतात.
