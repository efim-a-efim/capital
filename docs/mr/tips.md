# डेव्हलपरला टिप द्या

तुम्हाला डेव्हलपरला टिप द्यायची असल्यास, खालीलपैकी एक पद्धत वापरा. त्याने अॅपच्या कार्यक्षमतेत काहीही बदलणार नाही, पण डेव्हलपरला मदत होईल.

{% include tips.html %}

टिप म्हणजे तुमच्या स्वतःच्या वॉलेटमधून डेव्हलपरच्या पत्त्यावर केलेले हस्तांतरण. अॅप आणि ही साइट यात कोणताही भाग घेत नाहीत आणि ते पाहू शकत नाहीत; काहीही अनलॉक होत नाही, नोंदवले जात नाही किंवा बदलत नाही. हेच पत्ते अॅपमध्ये **आढावा** वरील हृदय बटणाखाली दाखवले जातात. गोपनीयता धोरणातील [देणग्या]({{ page.base }}/privacy#donations) पहा.
