## Design

- **Model**: `Bucket.pnl: Boolean = false`; `Flow(holdingId, date, amount, currency, source)` in `Portfolio.flows` (≤ 20 000, unique by holding+source+externalId); `Series` keys `qty:<holdingId>` (asset units; value in account currency for linked accounts). Depends on `add-rate-history` (`Series`, rate providers, schema 8 → this change ships as schema 9 only if fields are added after 8 is released; otherwise both land in 8).
- **Plugin API** (`BrokerPlugin`, both optional, default "unsupported"): `suspend fun flows(host, id, since: LocalDate): List<Flow>` returning deposits (+) and withdrawals (−) with the broker's own id; `suspend fun history(host, id, since): List<Pair<LocalDate, Reading>>` daily totals. The host validates dates, currencies and signs. Per broker, from the research (`.tools/pnl-research.md` copied into the change): IBKR `CashTransactions` (type Deposits & Withdrawals / Deposits/Withdrawals) + `EquitySummaryByReportDateInBase` (365 days per query, walked back year by year); OANDA `/transactions` TRANSFER_FUNDS; Trading 212 `/api/v0/equity/history/transactions` DEPOSIT/WITHDRAW; SnapTrade `/accounts/{id}/activities` CONTRIBUTION/WITHDRAWAL; Alpaca `/v2/account/activities` CSD/CSW + `/v2/account/portfolio/history`; Tradier `/history` ach/wire/check + `/historical-balances`; tastytrade `/transactions` Money Movement Deposit/Withdrawal + `/net-liq/history`; Public.com `/history` MONEY_MOVEMENT DEPOSIT/WITHDRAWAL; T-Invest `GetOperationsByCursor` INPUT*/OUTPUT*; Capital.com `/api/v1/history/transactions` DEPOSIT/WITHDRAWAL with explicit `from`/`to`; eToro `/api/v1/balances/history`.
- **Collection** (refresh): for every holding of a PnL bucket, append today's quantity when it differs from the last point; for linked accounts call `flows(since = last flow date − 90 days)` and merge by id; `history()` once at enable and then not again. Manual/wallet quantity deltas become flows valued at that day's rate.
- **Backfill** (`Pnl.backfill`, runs when the switch is turned on, with progress): list the folder's revisions, take the last one per day, record each holding's quantity and each quote as a history point (quotes become `rate:` points), then ask the rate providers for the missing days since the earliest point, then the brokers.
- **Calculation** (`domain/Pnl.kt`, pure, tested): bucket value per day `V(d) = Σ qty(h,d) × usd(asset,d) / usd(bucket,d)` carrying the last known point forward; flows per day in bucket currency; `pnl(a,b) = V(b) − V(a) − ΣF(a..b)`; `twr(a,b) = Π_{d} V(d) / (V(d−1) + F(d)) − 1`; periods all / 1y / 1m / 1w / 1d ending today; a period with no data shows "—".
- **UI**: `Heading(Investment)`; five `line`s "All time / Last year / Last month / Last week / Last day" with `+€1,234.56 · +3.4 %` coloured green/red; value chart and PnL chart with the FIRE chart's axes; chips All / 1Y / 1M / 1W / 1D (`FilterChip`) that set the visible range of both charts; a note when data starts after the period start ("since 12 Mar 2026").
- Plugin guide: new section on flows/history with the IBKR example.
